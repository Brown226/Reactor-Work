v1.0.0 当前版本 版本号取自仓库根 package.json · 基线条目

当前版本基线

  • 本仓特有能力：界面模式（编程 / 办公 / 审查）、文件审查板块、内网办公四件套、模型治理与开发者模式、内网服务端（身份底座 + 模型网关 + 管理台 API）。
  • 多端同一运行时：桌面端、Web 端与终端共用同一套会话运行时。
  • 任务体系：目标模式（目标管理 / 完成校验 / 状态恢复）、定时任务、闲时任务、编辑历史对话、会话分叉、辅助对话。
  • 扩展体系：插件、技能、MCP、命令、Hooks。
  • 内网分发：dist/zcode 发行包（TUI + Web + Agent）与 install.sh，须托管到内网可访问地址安装。
  • 各能力的详细行为见产品说明书对应页面。

更早版本未在此记录。发版时在「当前版本」上方新增条目，维护规则见本目录 README.md。
