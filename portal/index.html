核心能力

在同一个任务里，从规划走到验证收口

Reactor 围绕 Agent 工作流组织任务、权限、上下文与提交流，模型输出直接落到实际工程操作上。

长任务执行

需求理解、计划拆解、代码修改、验证与审查在同一个任务里完成；目标模式提供目标管理、完成校验与状态恢复。

多端跟进

桌面端、Web 端与终端共用同一套会话运行时；手机远控接入桌面已有会话，长任务执行中随时查看进度、补充指令。

企业模型治理

企业登录下，可选模型由内网服务端目录决定；模型调用统一走内网网关，可按人归属，本地模型配置由策略收敛。

部署

三步，把 Reactor 跑起来

所有命令从仓库根目录执行；运行时版本以仓库的 mise.toml 为准。

1

准备环境

克隆仓库，安装 Node.js 24 与 pnpm 10（版本以仓库声明为准）。

2

初始化

安装 workspace 依赖并准备桌面本地运行资源。

3

启动

桌面端开发用 dev:desktop；Web 端用 dev:web；正式分发用 bundle 打包。

terminal — 仓库根目录
# 初始化：依赖 + 桌面运行资源
pnpm bootstrap

# 桌面端（生产服务配置）
pnpm dev:desktop

# 打包桌面端安装产物
pnpm bundle:desktop -- --os win --arch x64

内网环境：构建期依赖下载须指向内网镜像（INTRANET_MACHINE_HOST / ZCODE_DEPS_BASE_URL，见仓库 .env.example）；未配置时构建会直接报错，不会静默回落公网。完整说明见安装与部署。
