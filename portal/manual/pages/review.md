## 审查能力一览

| 能力 | 说明 |
| --- | --- |
| 多格式审查 | Word / Excel / PDF / DWG 均可作为审查对象 |
| 一致性比对 | 多源文件之间比对，审查内容与范围由专业自行把控 |
| 文本校核 | 错别字 / 语法校对、引用标准规范版本校核、常规文本错误检查 |
| 编号与版次 | 图册编号、版次错误核查 |
| 专业意见 | 依据规则对方案 / 预算出具审查意见与报告 |
| 原文高亮 | 审查结果支持在原文档中高亮显示错误 |
| 报告输出 | 支持多种报告格式输出 |

> 审查结果由 AI 生成，结论请由专业人员复核后使用。
