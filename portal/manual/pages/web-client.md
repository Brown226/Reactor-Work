# Web 端（浏览器入口）

**Web 端**是 Reactor 在浏览器里的入口：不装客户端，用浏览器访问服务端地址即可登录使用，Agent 跑在服务器上，工作区与文件都在服务器侧。

它与桌面端**共用同一套前端**（界面、任务、对话、文件、预览基本一致），差异集中在入口装配与平台能力边界。这一页写给两类读者：只想用起来的读「访问与登录」「与桌面端的差异」；管理员读「部署注意」。

## 为什么有 Web 端

公司内仍有部分终端浏览器版本偏低（Win7 最高只能到 Chromium 109），也无法安装桌面客户端。Web 端让这些机器同样能进入 Reactor，且**刷新即最新**，不需要走客户端自动更新链路。

## 访问与登录

![Web 端登录页：组织账号与密码（服务端地址由部署入口锁定）](assets/img/web-login.png)

Web 端有两层入口，缺一不可：

| 层 | 作用 | 形式 |
| --- | --- | --- |
| 访问令牌 | 部署门禁：未授权的人连页面都拿不到 | 浏览器首次打开 `http://<服务器>:3030/?token=<访问令牌>`，换取本机 cookie |
| 企业登录 | 身份门禁：决定你是谁、能用哪些模型、看到哪个人的空间 | 组织账号 + 密码，服务端地址由 Web 容器经 `/api/server-info` 下发，登录页**不显示**地址输入框 |

- **登录态按浏览器会话隔离**：同一个浏览器文件（storage）对应一个登录会话，退出登录或清 cookie 后需要重新登录；不同浏览器、不同机器上的登录互不影响。
- **换账号**：退出登录后用另一个组织账号登录，界面与数据范围随之切换到该账号，不残留上一个账号的界面状态。
- **首次访问失败时**：确认地址里的 `token` 与服务端 `web/.env` 里配置的一致；令牌不对时页面不会进入工作区。

## 每用户工作区与隔离

登录后默认工作区 = **该用户自己的空间根目录**（服务端按登录链路记录的 uid 归属，不接受页面伪造的 uid）：

- 每用户独立目录与独立容量（默认 1GB），跨用户不可见、不可穿越；
- 服务端进程按每用户 uid 降权运行，Agent、MCP 与终端命令都落在这个身份上；
- 容量是软配额：先校验 `已用 + 本次`，超限直接拒绝，不会写一半失败。

资产的管理视图见[我的空间](my-space.md)。

## Web 端独有能力

| 能力 | 说明 | 页面 |
| --- | --- | --- |
| 我的空间 | 每用户 1GB 文件资产：上传 / 下载 / 预览 / 搜索 / 回收站 / 分享 / 历史版本 | [我的空间](my-space.md) |
| 分享链接 | 带有效期与可选提取码的公开下载链接，可随时撤销 | [我的空间](my-space.md) |
| 访问令牌门禁 | 部署方用令牌控制谁能打开页面，与企业登录各管一层 | 本页「访问与登录」 |
| 刷新即最新 | 服务端升级后刷新页面就是新版本，无安装、无回滚 | — |

## 与桌面端的差异

### 行为一致

对话与流式、中断重试、任务与会话管理、权限确认、工作区与文件树、文件预览（代码 / Markdown / PDF / Office / 图片）、Diff、Git、终端、技能与插件市场、MCP 读取启用、主题与语言、企业登录与账号切换、会话分享。

### 机制不同，结果一致

| 功能 | 桌面端 | Web 端 |
| --- | --- | --- |
| 附件 | 零上传直读本机路径 | 分片上传到服务端（单次 ≤ 8 个） |
| 工作区 | 本机任意目录 | 服务端上你的空间目录 |
| 终端 | 本机 shell | 服务端 shell |
| 更新 | 客户端自动更新 | 刷新即最新 |
| 凭据 | 操作系统钥匙串 | 服务端派生密钥 |
| 登录页 | 账号 / 密码 / **服务端地址**三项 | 账号 / 密码两项，地址由部署锁定 |

### Web 端不可用

本机任意目录作为工作区、在系统文件管理器里显示、外部编辑器打开、**内置浏览器面板与其驱动的浏览器自动化**、Computer Use（CUA）、Chrome 数据导入、操作系统钥匙串、客户端自动更新与回滚、托盘与任务栏徽标、关闭到托盘、全局快捷键、原生标题栏、独立窗口、开机自启、文件关联与右键菜单、导出日志到本地、离线使用、本机文件零上传。

> **提示**：界面上遇到点得动但静默失败的入口，就是这一类能力；正确的做法是改用桌面客户端，而不是反复重试。

## 部署注意

- Web 容器依赖 identity（登录）与 gateway（模型），缺任一条都表现为「能打开页面但用不了」。
- 访问令牌写在 Web 服务端 `web/.env` 的 `REACTOR_WEB_TOKEN`；升级部署想保留旧令牌，把旧值带过去即可。
- 登录跨域：Web 页面与身份接口不同源时，identity 需要把页面来源加入 `REACTOR_ALLOWED_ORIGINS` 白名单，否则预检被拒、登录 fetch failed。
- 配额与环境变量（每用户容量、总容量）见[服务端总览与接线](server-overview.md)与部署说明。
