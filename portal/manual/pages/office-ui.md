# 界面导览

![客户端主界面（办公 / 审查模式）](assets/img/client-main.png)

## 左侧导航

| 入口 | 用途 |
| --- | --- |
| 新建任务 | 开一条新对话，围绕一个目标开始工作 |
| 搜索 | 找历史任务与文件 |
| 自动化 | 定时任务、周期性工作 |
| 专家·技能 | 调用文档、数据、图纸、检索等专项能力 |
| 插件市场 | 查看与启用内置技能插件 |
| 项目 / 任务列表 | 按项目整理做过的任务，随时接着聊 |

## 中间工作区

- **问候与建议**：新建任务时给出常用场景入口；
- **输入框**：写需求、拖拽附件、`@` 添加上下文、`/` 选命令；
- **模式切换**：办公模式 / 审查模式，按当前任务选；
- **模型选择**：可在内置模型之间切换；
- **消息操作**：复制、赞踩、分叉、引用到新对话。

## 两种模式怎么选

| 模式 | 用在哪 |
| --- | --- |
| 办公模式 | 写文档、做表、汇总数据、整理文件、识别图纸文字 |
| 审查模式 | 合规核查、一致性比对、标准规范校核、出具审查意见 |

审查模式的详细流程见[审查版](review.md)。

## 底部提示

页面底部的红色文字是保密提醒：**本工具严禁上传和处理涉密文件，AI 生成内容仅供参考**。

## 数据在哪

对话、文件与产物按账号独立保存，别人看不到你的内容。退出重新登录后，历史任务和生成的文件都还在。
