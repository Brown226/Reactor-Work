# CAD 图纸审查

灵犀智伴配置了专业的 CAD 图纸解析工具与配套的图纸预览组件，图纸元素可与对话任务联动互通。

![CAD 图纸解析演示](assets/img/cad-demo.png)

## 审查能力

| 能力 | 说明 |
| --- | --- |
| 标准规范核查 | 解析图面内容中涉及的标准规范名称、年份并检查 |
| 批量抽表 | 自动识别位置、尺寸、图纸号、版次并输出 Excel |
| 文字智能修改 | 图面文字批量中英互转 |
| 图元联动 | 选中图纸元素后加入对话，针对具体位置继续核查 |

## 怎么用

1. 打开图纸，确认预览与图层显示正常；
2. 说明核查口径，例如「检查这张图引用的标准规范名称与年份是否正确」；
3. 对发现的问题，选中对应图元右键加入对话，让它解释或批量整理；
4. 需要台账时，用批量抽表把位置、尺寸、图纸号、版次输出成 Excel。

## 与其他审查配合

图纸抽表结果可以再交给[数据分析](office-data.md)做汇总比对，或与文档中的工程量、清单一起做一致性核查，形成完整证据链。

> 图纸识别结果受原图质量影响，关键尺寸与编号请对照原图复核。
