# 审查流程

## 一次审查的完整路径

1. **准备材料**：把待审文件（Word / Excel / PDF / DWG）放入任务，多份文件可以一起给；
2. **切换到审查模式**：输入框上方选择「审查模式」；
3. **说明审查口径**：写清楚依据什么、查什么、输出什么，例如「按公司采购制度检查这份合同的付款与验收条款，列出问题并标注原文位置」；
4. **逐条核查**：灵犀智伴逐条给出发现，标注原文位置，可跳转到对应段落；
5. **追问与引用**：选中某条发现，右键「加入对话」继续深挖，或让它补充依据；
6. **导出报告**：确认后导出审查意见或报告，支持多种格式。

## 审查口径怎么写更准

| 写法 | 效果 |
| --- | --- |
| 「检查一下这份文件」 | 太宽泛，容易泛泛而谈 |
| 「按《××规范》2023 版核对引用的标准编号与年份」 | 依据明确，结论可核对 |
| 「比对 A、B 两份文件中工程量与金额是否一致，列出差异」 | 范围明确，便于复核 |
| 「找出所有日期、金额，核对前后是否矛盾」 | 检查项清晰 |

## 多源文件一致性审查

把多份相关文件一起交给它，说明要比对的字段与口径。审查内容与范围由专业自行把控，可在实际应用中探索更大范围的使用方式。

## 结果与复核

所有发现都会标注原文位置，并支持原文档错误高亮。重要结论请人工复核，再进入正式意见或报告。见[审查结果与报告](review-report.md)。
