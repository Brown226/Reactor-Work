# 关于本说明书

![在线产品说明书](assets/img/manual-online.png)

**灵犀智伴（Reactor）** 是面向办公与专业工程场景的 Agent 智能体桌面客户端，由数字化管理科自主设计研发。产品围绕「文档生成 — 智能操作 — 自动办公 — 合规审查 — 数据分析 — 图纸识别 — 安全合规」构建能力闭环，支持数据本地化与商网运行，满足内网信息安全要求。

## 两册内容

本说明书按使用场景分为[日常办公版](office.md)与[审查版](review.md)两册，内容各自独立，可按需查阅。

## 版本与环境

| 项 | 说明 |
| --- | --- |
| 当前版本 | V1.1.1（以门户下载包版本号为准，后续持续迭代） |
| 运行环境 | Windows 10 及以上；商网 / 离线环境均可 |
| 内置模型 | 由单位统一提供与管控下发 |
| 数据 | 本地化存储与脱敏，核心功能离线可用 |

## 说明书说明

- 内容按当前交付版本整理，随产品升级同步更新；
- 界面截图为公测版本演示图，实际界面可能随版本略有差异；
- 全部页面为离线静态站点，双击任意 `.html` 即可浏览，不请求外部资源；
- 功能持续拓展，欢迎结合工作场景自行探索更多用法。
