# 关于本说明书

本页说明这份离线说明书的取材依据、称谓与路径口径、内容边界，以及帮助与排查入口。正文遇到疑问时，先回到这里对一下口径。

## 本说明书的取材方式

| 关注点 | 说明 |
| --- | --- |
| 依据 | 当前检出的本仓源码、`package.json` 与 `docs/` 下的契约 |
| 产品名 | Reactor（数智堆脑） |
| 部署形态 | 内网隔离部署，配自建服务端 |
| 模型接入 | 内网自建服务端与模型网关，含企业目录白名单 |
| 本仓新增能力 | 界面模式、文件审查板块、内网办公四件套、模型治理、内网服务端 |
| 在线商业与社群内容 | 与内网隔离部署无关，不收录 |

本说明书按本仓实际行为撰写：本仓没有的能力不写入，本仓新增的能力单列章节。

## 称谓与路径口径

阅读本说明书时，以下口径在全篇一致：

| 项 | 本说明书口径 | 说明 |
| --- | --- | --- |
| 产品名 | Reactor；需要全称时用 Reactor（数智堆脑） | 协议名、包名（如 `@zcode/shared`）与 `zcode` 命令名保留原名 |
| 用户级目录 | `~/.reactor` | 会话、凭据、用户级技能 / 命令 / 子智能体、CLI 日志等 |
| 工作区级目录 | `<项目根>/.zcode` | 项目配置的产品语义，保持原名 |
| 跨工具目录 | `~/.agents`、`~/.claude` | 跨工具约定目录，保持原名 |
| 环境变量 | `ZCODE_*` | 如 `ZCODE_DATA_BASE_DIR`、`ZCODE_HOME`，保持原名 |

用户级目录可用环境变量覆盖（优先级高于内置值）：`ZCODE_DATA_BASE_DIR` 指定数据基目录（用户数据根 = 其下的 `.reactor/`），`ZCODE_HOME` 直接指定用户数据根。详见[数据目录与背景主题契约](data-contracts.md)。

## 关于本说明书的边界

- 本说明书只描述**当前仓库提供的功能、命令与文件**；不存在的功能不写入，已移除的功能同步删除。
- 涉及状态所有者、事件顺序、失败语义的内容，以 `docs/` 下对应契约文档为准，本说明书只做面向使用者的转述。
- 与内网隔离部署无关的在线服务（下载站、套餐权益、社群入口、额度机制等）不收录。
- 凡无法在源码或契约中核实的条目，标注 `> **待核实**：...`，不用推测填充。
- 页面底部标注了「本页内容核对于某日期」的页面，表示该日期对照过当时的源码；未标注的页面不保证时效，以源码为准。
