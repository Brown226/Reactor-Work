# 图纸与图片

## 图纸（DWG / DXF）

上传 `.dwg` 或 `.dxf` 后可在浏览器里直接看图：缩放、平移、图层查看，不需要本机装 CAD 软件。

看图时可以：

- **右键选中实体加入对话**：把某根线、某个标注直接作为上下文；
- 让 AI 统计构件、核对标注、找差异；
- 把图纸内容整理成表格或说明文字。

## 图片与截图

- 支持常见图片格式预览；
- 截图、扫描件可以做 OCR 识别文字；
- 图片里的内容可以引用进对话，例如「按这张流程图写一份操作步骤」。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 图纸打开空白 | 确认文件完整，或让管理员重新上传 |
| 字体显示不对 | 图纸用了本机没有的字体，可让 AI 转成图片后再看 |
| 文件太大 | 先精简图纸或下载后用桌面端处理 |
