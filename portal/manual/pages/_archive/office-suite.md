# 文档 / 表格 / 演示

AI 可以直接处理日常办公文件，不需要你装 Office 插件。

## 能做什么

| 类型 | 常见操作 |
| --- | --- |
| Word（.docx） | 起草、改写、润色、提取要点、整理成目录、生成报告 |
| Excel（.xlsx） | 读表、统计、做透视、生成图表、整理成新表 |
| PPT（.pptx） | 生成演示页、改版式、补内容、把资料转成汇报稿 |
| PDF | 读内容、提取表格、转图片、合并拆分 |
| 图片 | 识别文字（OCR）、截图转写、格式转换 |

## 怎么用

1. 把文件拖进对话，或从[我的空间](my-space.md)加入；
2. 说清楚要什么，例如「把这份合同里的付款条款整理成一张表」；
3. AI 生成结果后，在[预览](preview.md)里确认，再下载。

## 预览能力

在「我的空间」里点开文件即可预览：

- Word / Excel / PPT / PDF / 图片 / DWG 都能在浏览器里看；
- PDF 与 PPT 支持翻页、缩放；
- 老版本浏览器（如 Win7 的 Chrome 109）用浏览器自带 PDF 查看器，功能一样可用。

## 注意

- 扫描件 PDF 需要先做 OCR 才能提取文字；
- 特别大的文件（超过 25MB）建议下载后用桌面端处理；
- 涉密文件不要上传，页面底部有保密提醒。
