# 登录与界面导览

## 登录

| 项 | 说明 |
| --- | --- |
| 入口 | 内网地址（由管理员提供，通常是 `http://<服务器IP>:3030/`） |
| 账号 | 企业账号 + 密码，由管理员分配 |
| 会话 | 每个浏览器一条独立登录状态；换浏览器要重新登录 |
| 老机器 | Win7 等无法装新桌面客户端的电脑，直接用浏览器即可 |

登录失败先核对账号密码；连续输错会暂时锁定，等一会儿再试。仍不行请联系管理员。

## 左侧导航

| 入口 | 用途 |
| --- | --- |
| 新建任务 | 开一条新对话 |
| 搜索 | 找历史任务、文件 |
| 我的空间 | 上传、管理、下载文件 |
| 自动化 | 定时任务与闲时任务 |
| 专家·技能 | 调用专项能力（如文档、表格、图纸） |
| 插件市场 | 查看已内置的插件能力 |

## 中间对话区

- **输入框**：写需求、拖拽附件、`@` 添加上下文、`/` 选命令；
- **模式**：编程 / 办公 / 审查三档，按当前任务切换；
- **变更前确认**：开启后，AI 改文件前会先征求你同意；
- **消息操作**：复制、赞/踩、分叉、引用到新对话。

## 右侧与顶部

- 顶部是当前任务名，可以重命名；
- 处理文件时可以打开预览面板，边看边聊；
- 页面底部的红色提示是保密提醒：**请勿上传和处理涉密文件**。

## 数据在哪

你的对话、文件、工作区都按账号独立存放，别人看不到你的内容。清理浏览器 Cookie 后会退出登录，重新登录即可，数据不会丢。
