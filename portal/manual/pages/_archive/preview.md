# 预览与下载

在[我的空间](my-space.md)或对话里点开文件，就能在浏览器里直接看，不用先下载。

## 支持预览的格式

| 格式 | 预览方式 |
| --- | --- |
| PDF | 翻页、缩放、打印（老浏览器用内置 PDF 查看器） |
| PPT / PPTX | 幻灯片缩略图、翻页、缩放 |
| Word / Excel | 版式预览 |
| 图片 | 缩放查看 |
| DWG / DXF | 图纸查看、选中实体加入对话 |
| 文本 / 代码 / Markdown | 直接阅读 |

## 下载

预览面板右上角有下载按钮；空间列表里也可以批量打包下载。生成的文件建议及时下载留档。

## 打不开时

| 现象 | 处理 |
| --- | --- |
| 一直转圈 | 刷新页面；文件过大时先下载 |
| 提示不支持 | 该格式暂不提供预览，先下载到本地打开 |
| PDF 空白 | 换用浏览器内置查看器，或下载后用本地 PDF 阅读器 |
| 图纸显示异常 | 见[图纸与图片](drawings.md) |

内网离线环境下预览不需要联网，全部资源都在服务器本地。
