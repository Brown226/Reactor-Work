# 发起任务与对话

## 写一条好用的需求

把「要什么、基于哪个文件、输出成什么样」说清楚即可：

> 基于我上传的《三季报.xlsx》，做一页总结 PPT，突出收入变化，用中文。

不需要写命令行，也不需要懂配置。说得越具体，结果越准。

## 输入框里的小工具

| 操作 | 作用 |
| --- | --- |
| 拖拽文件 | 把本地文件加入对话 |
| `@` | 引用工作区或我的空间里的文件 |
| `/` | 选择命令或专项能力 |
| 变更前确认 | 让 AI 在改文件前先问你 |
| 模式切换 | 编程 / 办公 / 审查，按场景选 |

## 对话过程中

AI 会展示思考、读取了哪些文件、调用了什么能力、执行结果。你可以随时：

- **补充要求**：「表格按月份排序」「再加一页风险提示」；
- **打断 / 停止**：不合适就停；
- **引用进对话**：选中一段文字或界面元素，右键「加入对话」；
- **分叉**：从某条消息拉出一条新对话，保留原对话。

## 结果怎么拿

- 文字内容直接复制；
- 生成的文件会落到[我的空间](my-space.md)，可[预览](preview.md)或下载；
- 需要继续加工，就在同一条对话里接着说，不用重新上传。

## 常见误区

- 让 AI「去网上搜一下」——内网无外网，做不到；请直接给文件。
- 一次塞太多无关文件——先给最相关的，效果更好。
- 任务太大不问进度——可以中途追问「做到哪一步了」。
