# 我的空间

「我的空间」是你在服务器上的个人文件区，每个账号独立，默认 1GB。

## 能做什么

| 操作 | 说明 |
| --- | --- |
| 上传 | 拖拽或选文件，支持断点续传与同名自动编号 |
| 新建文件夹 | 按项目整理资料 |
| 搜索 | 按文件名找文件 |
| 预览 | 文档、表格、PPT、PDF、图片、DWG 直接在浏览器里看 |
| 下载 | 单个文件或打包下载 |
| 版本历史 | 编辑过的文件可回溯、还原 |
| 分享 | 生成链接给同事 |
| 回收站 | 误删可恢复，占用空间会计算在内 |

## 和对话的关系

- 对话里上传的附件自动进「对话附件」目录；
- 生成的文件也在空间里，随时可以再用；
- 空间里的文件可以用 `@` 直接加入新对话。

## 容量

右上角可以看到已用空间。快满时先清回收站、删掉不再需要的旧版本。上传临时文件、历史版本都占额度。

## 注意

- 不要上传涉密文件；
- 清理回收站后才真正释放空间；
- 换账号登录看到的是另一个空间，数据不互通。
