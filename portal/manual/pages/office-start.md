# 快速开始

## 1. 获取与安装

单位门户提供安装包、使用说明书与版本更新日志，下载后按向导安装即可。当前公测版本为 **V1.1.1**，以门户下载包版本号为准。

> 运行环境：支持 Windows 10；Win7 因底层框架版本限制暂不支持。商网 / 离线环境均可运行，无需外网。

## 2. 登录

![账号登录界面](assets/img/login.png)

| 项 | 说明 |
| --- | --- |
| 账号 | 个人龙语账号（如 `tiankd`） |
| 初始密码 | `用户名@123`（如 `tiankd@123`） |
| 首次登录 | 按提示**强制修改密码**，改密后正常使用 |
| 服务端地址 | 安装包已按单位配置预置，直接登录即可 |

登录失败先核对账号与密码；连续输错会暂时锁定，稍后再试。

## 3. 发第一句话

在输入框写清楚「要什么、基于哪个文件、输出成什么样」，例如：

- 「根据这份季度数据生成一页汇报 PPT，突出收入变化」
- 「把这份会议录音转写整理成纪要初稿」
- 「读一下这个预算表，按部门汇总并标出异常项」

按回车或点发送，灵犀智伴开始工作。过程中能看到它的思考、读取的文件与执行结果。

## 4. 把资料给它

- 拖拽文件到输入框；
- 用 `@` 添加本地文件作为上下文；
- 用 `/` 选择命令或专项能力。

## 5. 拿结果、继续改

生成的内容可以直接看，也可以继续在同一条对话里说「再精简一点」「换成表格」「补一页风险提示」。生成的文件会保存在工作区，随时能打开、下载或再次加工，见[文件与产物管理](office-space.md)。

## 内置模型使用提示

单位统一提供两个内置模型：多模态模型适合图纸、图片与文档理解，对话模型适合日常问答与写作。多模态模型并发资源有限，遇到排队时稍后重试，或把任务分配到对话模型即可。
