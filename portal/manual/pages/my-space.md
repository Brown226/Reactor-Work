# 我的空间

**我的空间**是 Web 端每用户独立的文件资产视图：上传、下载、预览、搜索、回收站、分享与历史版本都在这一个页面里完成，容量按人隔离，默认 1GB。

> **Web 端独有**：我的空间只有 Web 宿主会渲染入口（桌面端不显示「我的空间」，本机目录就是桌面端的工作区）。桌面端没有这一页，也没有这套空间接口。

这一页写给两类读者：只想管文件的人读「文件管理」「回收站」「分享」三节；要把它接进工作流的人再读「与 Agent 的联动」。

## 是什么

我的空间与工作区指向**同一份磁盘数据**：登录后默认工作区就是该用户的空间根目录，Agent 产出的文件天然落在空间里；我的空间页只是面向人的管理视图，不做二次同步。

| 概念 | 口径 |
| --- | --- |
| 空间根 | 每用户一个独立目录，跨用户不可见 |
| 容量 | 每用户默认 1GB（`REACTOR_WEB_USER_QUOTA_BYTES`，可按部署调整）；容器总配额约 20GB，软配额 |
| 占用统计 | `usedBytes` 含回收站；目录项开销忽略 |
| 分类 | 文档 / 图片 / 图纸 / 其他，容量卡按分类给出占比 |

## 入口

侧边栏「我的空间」进入。页面分三块：顶部标签页（文件 / 回收站 / 分享）与搜索框，左侧文件列表，右侧详情与预览；窄屏下详情改为弹窗，任何宽度都能预览。

## 文件管理

![我的空间文件列表与容量卡（图中为演示数据）](assets/img/my-space-files.png)

- **上传**：点右上「上传文件」选择文件；同名文件自动加 ` (1)` 后缀，不覆盖已有内容。大文件走分片上传，可断点续传。
- **拖拽上传**：把文件拖到列表区即可。
- **下载**：单文件下载；勾选多项可「打包下载」（zip 流）。
- **新建文件夹 / 重命名 / 移动**：顶部「更多」菜单新建文件夹；行内更多菜单与右键操作一致，统一走弹窗确认，不用浏览器 prompt。
- **删除**：删除先进回收站，仍占容量；彻底删除才释放。
- **搜索**：右上搜索框按文件名递归搜索，跳过内部目录，上限 500 条。
- **批量操作**：勾选后可批量删除、打包下载。

## 预览

![选中 Markdown 文件的详情与预览（图中为演示数据）](assets/img/my-space-preview.png)

选中文件后在右侧查看详情与预览，除文档类外还支持：

| 类型 | 预览方式 |
| --- | --- |
| 图片（png/jpg/gif/webp/svg…） | 直接渲染 |
| PDF | 翻页 / 缩放 |
| doc/docx/xls/xlsx/ppt/pptx | Office 预览组件 |
| md / 代码 / 纯文本 | Markdown 渲染 / 代码高亮 |
| 音频、视频 | 原生播放器 |
| dwg / dxf | 服务端解析后在线查看（见[DWG 预览相关说明](data-contracts.md)） |

比桌面端预览面板少的能力：代码行内评论、审查定位高亮、PDF 引文进会话、PPT 元素引用——这些依赖桌面端的会话与审查上下文，不在空间页范围内。

## 回收站

删除的文件进入回收站（`.trash`），**仍然占用空间**，可随时还原；「清空回收站」或彻底删除后才真正释放容量。回收站对空间页可见，对工作区文件树隐藏。

## 分享

![分享弹窗：有效期与提取码（图中为演示数据）](assets/img/my-space-share.png)

1. 选中文件 → 点「分享链接」。
2. 设置有效期（小时）与可选的提取码，生成链接。
3. 「分享」标签页管理已创建的分享：复制链接、撤销。

拿到链接的人可在有效期内直接下载；设了提取码会再校验一次。**公开下载只允许文件，不允许目录**；分享 token 为 32 字节随机，口令只存哈希。撤销后链接立即失效。

## 历史版本

对选中的文件可用「上传新版本」覆盖同名文件：旧内容归档到 `.versions`，在详情里可查看历史版本并还原。适合同一份文档反复修订、需要回看的场景。

## 与 Agent 的联动

- **默认工作区即空间根**：登录后工作区直接落在你的空间里，Agent 读写、生成的文件都归你所有，不存在「产出落在别人目录」的问题。
- **对话附件自动归集**：Web 端对话里上传的附件会按上传通道落到空间目录，任务结束后仍可管理、可复用。
- **加入对话**：详情页「加入对话」把文件注入当前会话，让 Agent 围绕它工作。
- **配额前置校验**：上传前先算 `usedBytes + 本次大小`，超限直接拒绝，不会先写一半再失败。

## 配额与限制

| 项 | 口径 |
| --- | --- |
| 单用户容量 | 默认 1GB，含回收站 |
| 上传同名 | 自动加 ` (1)`，不覆盖 |
| 预览上限 | Office 类 25MB，Markdown / 文本 2MB |
| 搜索上限 | 500 条结果 |
| 公开下载 | 仅文件，需在有效期内，提取码可选 |

配额满时的处理顺序：先清回收站（彻底删除），再删重复版本，最后把大文件下载到本地后从空间移除。
