# 文档合规审查

## 支持的文件

Word、Excel、PDF 以及 DWG 图纸均可作为审查对象；多份文件可一起做一致性比对。

## 能查什么

| 检查项 | 说明 |
| --- | --- |
| 错别字 / 语法 | 校对文字错误、语句不通、表述不一致 |
| 引用标准规范 | 校核引用的标准名称、编号与版本年份是否为现行有效版本 |
| 常规文本错误 | 编号、单位、日期、金额等前后矛盾 |
| 图册编号 / 版次 | 核查图册编号与版次是否一致、是否存在错漏 |
| 方案 / 预算 | 依据规则出具审查意见与报告 |

## 典型用法

- 「核对本文引用的标准规范名称与年份，列出已废止或版本不匹配的条目」；
- 「比对技术方案与预算书的工程量，列出差异并标注出处」；
- 「检查全套图册的编号与版次，输出问题清单」；
- 「按给定规则对这份方案出具审查意见，分条列出依据」。

## 原文高亮与定位

审查发现会对应到原文位置：点击可跳转，原文档中的错误支持高亮显示，便于逐条复核与留痕。

> 规则与依据由专业口径提供，AI 负责检索、比对与整理；结论请由专业人员确认。
