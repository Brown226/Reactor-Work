# 文件与产物管理

## 生成的文件去哪了

对话中生成的文档、表格、PPT、PDF、抽取结果都会保存在你的工作区与产物目录里，按任务归档。可以在任务里点开，也可以在文件区按名称查找。

## 常用操作

| 操作 | 说明 |
| --- | --- |
| 打开 / 预览 | 文档、表格、PPT、PDF、图片、图纸直接在客户端里看 |
| 下载 | 把成稿保存到本地指定目录 |
| 继续加工 | 从产物直接发起新对话，不用重新上传 |
| 整理归档 | 按项目、时间或类型归类，便于复用 |

## 上传的资料

拖拽到输入框或用 `@` 引用的文件会保留在任务上下文里，之后仍可在文件区找到。同名文件会自动编号，不会覆盖原件。

## 空间与容量

文件区有容量提示，快满时可清理不再需要的中间产物与历史版本。删掉的文件先进回收站，可恢复；清理回收站后才真正释放空间。

## 数据隔离

每个账号的文件、对话与产物彼此独立；换账号登录看到的是另一个空间。数据保存在单位内网，不传到外网。
