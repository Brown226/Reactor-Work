# 文档智能生成

基于大模型与内置离线文档解析引擎，用自然语言对话就能生成与修改办公文档，断网也能出件。

## 能生成什么

| 类型 | 典型产出 |
| --- | --- |
| Word | 工作报告、技术规格书、设计说明初稿、会议纪要、制度文稿 |
| Excel | 报表、汇总表、清单、台账 |
| PPT | 汇报演示、评审材料、培训提纲 |
| PDF | 定稿文件、报告输出、格式转换 |
| 文字优化 | 党建新闻宣传文稿、专业稿件润色、结构重排 |

## 怎么用

1. 说清楚文档类型、用途与要点，例如「按这份素材生成一页季度汇报 PPT，中文、三要点」；
2. 有参考资料就拖进输入框，或用 `@` 引用；
3. 初稿出来后在同一条对话里继续改：「标题换成…」「第二节展开」「加一页数据图表」；
4. 定稿后在[文件与产物管理](office-space.md)里打开或下载。

## 成稿后继续修改

灵犀智伴会保留上下文，改版式、补内容、换口径都不用重新上传。

## 会议纪要与素材整理

- 文本转纪要初稿：把讨论记录、录音转写贴进来，让它提炼议题、结论与待办；
- 多份材料合稿：把几份文件一起给它，按统一结构输出；
- 文字优化：给它一段草稿，说明「更正式 / 更简洁 / 面向汇报」，即可出改写稿。

> 生成内容由 AI 产出，涉及数据、口径与结论时请人工复核后再使用。
