# 数据分析与图表

内置图表组件，可对多源数据做汇总、比对与趋势分析，并生成专业图表报告。

## 典型场景

| 场景 | 能做什么 |
| --- | --- |
| 工程量 / 预算 | 工程量、预算书、图册工程量、预结算审核书的智能汇总与格式转换 |
| 表格抽取 | CAD 图纸材料表、PDF 表格、扫描件表格抽取成可编辑数据 |
| 异常分析 | 薪酬、预算按阈值比对，标出异常项 |
| 财务核算 | 汇总、核对、口径统一 |
| 设计管理 | 设计质量数据（DEN / FCR / CR）汇报与趋势预测 |

## 怎么用

1. 把数据表、预算书、图纸或 PDF 一起交给它；
2. 说明分析口径与输出形式，例如「按月份汇总费用，标出超过预算 10% 的部门，输出图表」；
3. 结果里会给出表格、图表与说明文字，可继续追问或导出。

## 输出形式

- 汇总表与明细表；
- 柱状、折线、占比等图表；
- 带结论的分析报告，可直接并入汇报材料。

> 涉及金额、工程量等关键数据，请以原始数据为准进行复核。
