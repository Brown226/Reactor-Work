# 审查结果与报告

## 结果怎么看

每条审查发现通常包含：

- **问题概述**：哪里不一致 / 哪里存疑；
- **原文位置**：对应段落、单元格或图元，可跳转；
- **依据**：所用规则、规范版本或比对口径；
- **建议**：可选的处理方向。

## 原文高亮

审查结果支持在软件中对原文档错误进行高亮显示，便于逐条核对、截图留痕与向同事说明。左侧按「内容一致性 / 逻辑一致性 / 内容完整性」等维度分组展示问题，右侧原文对应位置高亮并给出说明。

## 报告输出

支持多种报告格式输出，可按需要选择：

| 输出 | 适用 |
| --- | --- |
| 问题清单 | 内部核对、逐条销项 |
| 审查意见 | 按规则形成的正式意见稿 |
| 比对表 | 多源文件差异对照 |
| 汇总报告 | 提交评审或归档 |

## 复核与留痕

1. 逐条核对发现与原文，剔除误报；
2. 补充专业判断与依据；
3. 导出报告后按单位流程归档。

> AI 生成内容仅供参考，正式审查结论须由专业人员复核确认。
