# 标点与排版检查口径

> 只列**确定性**可判的条目。"这里应该分段"这类排版偏好不进本表。

## 一、标点

| 检查项 | 判定 | 严重度 |
| --- | --- | --- |
| 中文句子用了半角逗号/句号（`,` `.`） | 应为全角 `，` `。` | `warning` |
| 中文句子用了英文括号 `()` 包裹中文 | 应为全角 `（）`；但包裹纯英文/编号时保留半角 | `warning` |
| 顿号与逗号混用并列项 | 中文并列名词用 `、`，并列分句用 `，` | `warning` |
| 书名号/标准号上的标点 | 《…》与 GB/T xxxxx 之间不加顿号；编号本身不带标点 | `info` |
| 连续标点（`。。`、`，，`、`；；`） | 重复标点 | `error` |
| 全角引号内的引号嵌套 | 内层用单引号 `『』` 或按公司模板 | `info` |
| 破折号/连接号 | 中文用 `—`（占两格），数值区间用 `～` 或 `-`，**不要混用** | `warning` |

## 二、单位与量纲

| 检查项 | 正确写法 | 严重度 |
| --- | --- | --- |
| 压力 | `MPa`（不是 `Mpa`/`MPA`/`mPa`） | `error` |
| 功率 | `kW`（不是 `KW`/`kw`/`Kw`） | `error` |
| 流量 | `m³/h`、`t/h`；全文只用一种 | `warning` |
| 温度 | `℃` 或 `°C`；全文统一 | `warning` |
| 公称直径 | `DN200`（不大写间距写成 `DN 200`）；管道规格 `φ89×3.2` | `warning` |
| 浓度/含量 | 百分号与中文之间不留空格（`5%`），数值与单位间留半角空格（`5 m`） | `info` |
| 单位符号复数 | 中文语境不加 `s`（不写 `kgs`） | `error` |

## 三、中英文混排

| 检查项 | 判定 | 严重度 |
| --- | --- | --- |
| 中文与英文/数字之间缺半角空格 | 如 `CEH物项编码` → `CEH 物项编码`；**编号与型号内部不算**（`DN200`、`GB50974`） | `warning` |
| 全角字母数字（`ＡＢ１２`） | 一律改半角 | `error` |
| 英文句子用了中文标点 | 与所在句子主体语言一致 | `info` |

## 四、编号与称谓

- 图册编号/文件编码/工程号在**封面、页眉、目录、正文**四处必须逐字一致（不一致一律 `error`）。
- 版次、状态码（`CFC`/`PRE`/`IFA`/`IFU`/`DES`）、设计阶段用词按公司模板取值，非标准值报 `warning`。
- 同一实体在全文的称谓统一；首次出现给全称 + 简称，之后用简称。

## 五、不要报的（已验证的误报来源）

- 「其它」（虽推荐「其他」，但不是错别字）、「可建面积」、「通志」等**合法用法**——已在错别字表源头剔除，不要凭语感补报。
- 标准编号内部的空格/连接号差异（`GB/T 8163-2018` 与 `GB/T8163-2018`）——属引用规范问题，交给「标准引用自检」，
  不在校对里重复报。
- 表格对齐、行距、字号等排版问题（本技能不检查版面）。
