# 常见错别字映射表（确定性部分）

> 来源：核审通 `backend/src/services/rules/typo.rule.ts` 的 `TYPO_MAP`，**逐条迁移**（共 218 条，
> 已在源头剔除的误配条目不再引入）。这里只放**确定性命中**的错别字对；语义级用词问题由模型判断。

## 用法

1. 用下表逐条扫描正文，命中即报 `error`（错别字是硬错误，不是建议）。
2. **先过术语白名单**：调用 `KnowledgeCheck`（`action=terminology`）把候选丢掉——专业词误报是这类审查
   最主要的噪音来源（例如「安全壳」「常规岛」这类词本身不该被任何规则标记）。
3. 每条必须给出**原文片段**（命中的词及其前后各 15 字上下文），否则无法定位复核。
4. 同一错词最多报 3 处（避免一份文件里同一个字刷屏），其余汇总成「另有 N 处」。
5. 区间外的情况：只出现在图表标题、编号、专有名词内部时仍要报，但要在描述里写明位置。
