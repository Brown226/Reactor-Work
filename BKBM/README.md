# BKBM：PKPM Agent 解析与工程能力移植

本目录存放 BKBM 分支的全部解析产物与设计文档。代码实现位于
`packages/services/src/engineering/`，本目录只放「依据与素材」，不放运行代码。

## 目录说明

| 目录 | 内容 | 用途 |
| --- | --- | --- |
| `分析文档/` | 架构还原、移植方案、资产清单、前端还原 | 设计与实施依据，先看这里 |
| `逆向工程/` | plants 模块逻辑还原、1379 条接口签名 | 理解被编译部分的原有设计 |
| `可复用脚本/` | 103 个明文脚本，按 A/B/C/D 分级 | 可直接取用的工程实现 |
| `技能正文/` | 22 份技能说明（已解密） | 各软件的调用范式与踩坑记录 |
| `明文源码/` | 333 个明文文件 | 原始素材，未加工 |
| `前端文案/` | 617 条界面文案 | 交互设计与提示语参考 |

### 拿不到的

| 项 | 原因 |
| --- | --- |
| 核心引擎实现（20MB `.pyd`） | Cython 编译为机器码，不可逆 |
| 前端源码（431 个 chunk） | 混淆且无 sourcemap |
| 系统提示词 | 在 `agent.pyd` 内 |

### 一个关键澄清

原始软件联动其他软件**不是屏幕镜像**，是 API 直连：Agent 下发指令，
软件在自身图形内核里执行并渲染，Agent 读取结构化数据（节点坐标、
构件 ID、截面参数）。不采集屏幕、不嵌入窗口、不读像素。
