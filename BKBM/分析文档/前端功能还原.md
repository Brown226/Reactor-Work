## 四、从文案直接读出的关键设计

### ① 授权是双通道
```
"本机已验出锁码授权，可以不登录直接使用。但 PKPM 云端模型需要登录后才能取用"
"登录需要连接构力云服务器，当前只能使用锁码授权"
```
→ **离线锁码 + 云端账号**两套并行，跟后端 auth/*.pyd 对上。

### ② 上下文压缩是显式可配的
```
"模型支持的最大上下文。比设置中的上下文长度小时，按这里的值决定何时自动压缩。"
```
→ 压缩阈值 = min(模型上限, 设置值)，印证后端 `_auto_compaction_threshold()`。

### ③ 知识库是 Wiki 结构（不是文件柜）
```
"创建 Wiki 知识库失败"
"删除后，该文件夹及其中的内容将从知识库移除"
"全部知识库将搬到 {root}... 存在不同版本的知识库会保留两份并自动改名"
```
→ 对应后端 `wiki_store.pyd` + `knowledge_browse/search` 两个 API。

### ④ 语义索引是异步增量更新的
```
"正在更新语义索引 · {done} / {total}，关键词搜索可正常使用。"
"正在准备语义检索，关键词搜索可正常使用。"
```
→ 降级设计：语义索引没建好时，关键词搜索不受影响。对应 `semantic_runtime.pyd`。

### ⑤ 脚本是"从对话沉淀"的
```
"# 在 Agent 中描述您的需求，完成任务后点消息下方的「插件 & 脚本 → 保存到脚本」"
```
→ **对话 → 脚本 → 插件的三级沉淀路径**，跟后端 skill/plugin_kit 对上。

### ⑥ 关闭窗口有确认
```
"关闭窗口时您希望执行什么操作？退出应用将停止所有正在运行的任务。"
```
→ 对应后端 `main.py` 里那段"父进程消失自我了断"的逻辑。

| 能借鉴 | 怎么用 |
