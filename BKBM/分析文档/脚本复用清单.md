## D 类：换 1 行（19 个 / 3,310 行）

全部是 API 检索器，只因为用了 `vault.connect_db()`（解密库）。**我们用明文库后，改一行即可：**

```python
# 原：
from PKPMAgent.skill_kit.vault import connect_db
conn = connect_db(DB_PATH)

# 改：
import sqlite3
conn = sqlite3.connect(DB_PATH)      # 解密后的库就是标准 SQLite
```

涉及：ETABS×4、SAP2000×4、STAAD×3、Rhino×3、Tekla×2、MIDAS×1、SketchUp×1、Abaqus×1
