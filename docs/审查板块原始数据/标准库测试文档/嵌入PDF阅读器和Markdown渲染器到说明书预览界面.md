## 1. 技术选型

### 1.1 PDF渲染
- **库选择**：PDF.js
- **理由**：
  - 纯前端解决方案，由Mozilla开发，开源免费
  - 支持内网离线运行，无需依赖外部服务
  - 兼容性好，支持所有现代浏览器
  - 功能丰富，支持缩放、翻页、搜索等基础操作
  - 可以直接从URL加载PDF文件

### 1.2 Markdown渲染
- **库选择**：marked
- **理由**：
  - 纯前端Markdown解析器，轻量级
  - 支持内网离线运行
  - 解析速度快，性能良好
  - 支持自定义渲染选项，可以美化输出格式
  - 可以配合CSS实现美观的排版
