# 已完成：专家·技能市场卡片样式优化

- 状态：已完成（2026-10-12）
- 范围：仅卡片视觉，不动信息架构、状态、服务接线

## 背景

大王反馈市场卡片「样式可以好看一些」，并明确 **不做大改**。因此本次只收敛
`packages/ui/src/marketplace/MarketPage.tsx` 内三个卡片组件（`ExpertCard`、`SkillCard`、
`BundleCard`）的视觉，页面结构、筛选/排序/搜索/弹层接线一律不动。

## 改动清单（纯 className，无逻辑改动）

三个卡片同构，改动一致：

| 项 | 改前 | 改后 | 依据 |
| --- | --- | --- | --- |
| 图标背板圆角 | `rounded-xl` | `rounded-lg` | DESIGN.md Radius：嵌套圆角必须降级，同级 `rounded-xl` 违反层级 |
| 标题字重 | `font-medium` | `font-semibold` | 卡片标题层级强化，与 `PluginStoreCard` 一致 |
| hover 反馈 | 仅 `hover:bg-card-selected` | 追加 `hover:border-border-hover` | 仓库既有约定（`button.tsx` 等）；网格扫描时定位感更清晰 |
| 焦点态 | 无 | `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-input-border-focused` | DESIGN.md「键盘导航是一等交互路径」；卡片是 `<button>`，此前无可达焦点样式 |
| 卡片内边距 | `p-4` | `p-3.5` | 与 `PluginStoreCard`（`px-2 py-2.5` 体量）拉齐，卡片更紧凑 |

保持不动的部分（有意为之）：

- 卡片外壳 `rounded-xl border border-card-border bg-card` —— DESIGN.md Cards and Panels 明文规定。
- 不加 `shadow-*` —— DESIGN.md Elevation：卡片属 Base/Surface 级，层级靠背景对比与边框，禁止依赖重阴影。
- 网格列数、chips、tab、排序、搜索全部不动。
- `tags` / `author` / `installed` 徽标的渲染逻辑不动（属信息密度议题，不在「改样式」范围）。
