# 已完成：技能卡片「使用」入口（仿 NewMax 卡片调用逻辑）

- 状态：已完成（2026-10-12）
- 范围：仅技能卡片 + 技能详情弹层的「使用」动作接线；不动专家卡、套件卡、服务端契约

## 背景

大王反馈：市场技能卡片在安装后应像参考图（NewMax Skill 市场）那样提供**可直接点击的
「使用」入口**，点击后即在对话框中带上该技能调用；此前技能装完只能靠用户自己去输入框
手打 `$技能名`，市场页与对话之间没有通路。

## 关键事实（源码核实）

| 事实 | 依据 |
| --- | --- |
| 对话框调用技能 = 插入 `$技能名` mention | `mentions/mentionMarkdown.ts:68` `buildSkillMentionMarkdown(label, skillPath?)`，无 path 时产出纯 `$label`；`mentionMarkdown.ts:4` 的 `INLINE_MENTION_TOKEN_PATTERN` 把 `$xxx` 解析为 skill part |
| 技能 mention 面板只列启用态技能 | `mentions/providers/skillsMentionProvider.ts:84` `filter((skill) => skill.enabled)` |
| 专家卡已有同款范式 | `MarketPage.tsx:372-389` `handleExpertStarter` → `onCreateTask({ initialPrompt, initialPromptMention })` |
| `onCreateTask` 的完整语义 | `root/useRootWorkspaceActions.ts:250-280`：`startDraft` → `persistV4ComposerDraft` → `requestComposerTextInsert`，即「新建会话并把 mention 插入输入框」，**不自动发送** |
| `ServerSkillCatalogItem` 无 path 字段 | `packages/shared/src/server-skills-market-types.ts:26-66`，故只能组装 `$name` 形态，无法组装带路径的链接 mention |
| 安装后 `installed` 会刷新 | `hooks/useServerSkillMarket.ts:122-131` install 成功后 `syncCatalog()` re-GET，卡片即时反映 |

## 方案

与专家召唤（`@专家名`）完全对称，技能走 `$技能名`：

1. **新增纯逻辑模块 `packages/ui/src/marketplace/skillUsage.ts`**
   - `buildSkillUsePrefill(name, title?)`：组装 `ComposerMentionPrefill`（`category: "skills"`，
     `markdown: buildSkillMentionMarkdown(name)`）。
   - `shouldShowSkillUseAction({ installed, enabled, hasCreateTask })`：三者皆真才显示入口。
     `enabled` 条件与 mention 面板的过滤口径一致——停用的技能在 `$` 面板里不存在，
     此时给按钮只会制造死入口。
2. **`MarketPage.tsx`**
   - `SkillCard` 外壳由 `<button>` 改为 `<div>`（内嵌按钮在 HTML 非法），主体点击区仍是
     `<button>`（开详情，焦点/hover 样式不变），「使用」作为右上角独立 `<button>`，
     与「已安装」徽章并排。
   - 新增 `handleSkillStarter`，复用一个 `onCreateTask` 通道，不新建写入路径。
   - 详情弹层透传 `onUse`（安装后显示），与专家的 `onStarter`/`onSummon` 接线同形。
3. **`SkillDetailDialog.tsx`**：新增可选 `onUse`，安装后渲染「使用」按钮。
4. **i18n**：新增 `marketplace.card.use` / `marketplace.dialog.use`（zh-CN + en-US）。

## 不改动的部分（有意为之）

- **不自动发送**：与 `onCreateTask` 的契约和专家召唤一致，只预填草稿。技能无 starters
  字段（`server-skills-market-types.ts:64-65` §7-U7 已核实服务端暂无），无法替用户编任务描述，
  也不该编。
- 不动专家卡/套件卡/网格/chips/排序/搜索。
- 不动服务端契约——本改动纯客户端，`enabled` 等字段服务端已下发。

## 验收场景

| # | 场景 | 预期 |
| --- | --- | --- |
| 1 | 未安装技能 | 卡片无「使用」按钮 |
| 2 | 已安装 + `enabled` + 宿主提供 `onCreateTask` | 右上角显示「使用」；点击后新建会话，输入框预填 `$技能名` mention（不发送） |

| 5 | 详情弹层安装后 | 显示「使用」，行为与卡片一致 |
| 6 | 点击卡片主体 | 仍开详情弹层（外壳改 div 不退化为不可达） |
