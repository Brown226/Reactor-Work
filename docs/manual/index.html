Reactor 产品说明书

Reactor（数智堆脑） 是面向内网环境部署的 Agentic Development Environment（ADE）：把大模型的长上下文与长程任务能力，落到桌面端、Web 端与终端里可连续推进的开发工作流上。

本说明书依据当前检出的源码整理，描述的是本仓库实际提供的能力、命令、配置项与文件位置。它与上游 ZCode 官方文档存在差异，凡属本仓二次开发新增、上游没有或已改动的部分，均在本说明书中单独标注。
