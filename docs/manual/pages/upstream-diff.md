# 与上游 ZCode 的差异

本说明书由上游 ZCode 官方中文文档改写而来。改写不是翻译，而是**按本仓实际行为重写**：上游有的能力本仓若无，则不写；本仓新增的能力，单列章节。

本页是差异总表，供快速对照。逐页差异在各页末尾的「与上游 ZCode 的差异」小节。

## 1. 基本口径对照

| 维度 | 上游 ZCode | Reactor（本仓） |
| --- | --- | --- |
| 产品名 | ZCode | Reactor（数智堆脑） |
| 定位 | 公网可用的 ADE，围绕 GLM-5.3 深度联调 | 内网隔离部署的 ADE，围绕内网模型网关 |
| 版本 | 官方站当前 3.14.4 | 本仓 `package.json` 为 3.14.0 |
| 用户级数据目录 | `~/.zcode` | `~/.reactor` |
| 工作区级目录 | `<repo>/.zcode` | `<repo>/.zcode`（未变） |
| 模型接入 | 官方 GLM Coding Plan / Z.ai / BigModel 等公网端点 | 内网自建服务端与模型网关 |
| 插件市场 | 官方 CDN（`cdn-zcode.z.ai`）分片 | 默认禁用 CDN 分片，只用随包内置；办公四件套已 fork 进仓库 |
| 计费与额度 | Coding Plan、周额度、额度重置卡 | 不适用（内网服务端自行计量） |

## 5. 需要特别提请注意的三点

### 5.1 两条实时链路语义不同

桌面端走 `desktop-continuous`（直连实时流），手机与 Web 远端走 `web-remote-replayable`（快照 + 断档修复）。两者**共用同一状态所有者与序列**，但交付语义不同。修改流、快照、队列或重连时，必须同时验证两种语义。详见[手机远控](remote-control.md)。

### 5.2 手机远控复用桌面已有会话

手机端是**控制界面**，不为手机另起 Agent、Local Host 或远程会话；它接入的是桌面端已有的 Host attachment。详见[手机远控](remote-control.md)。

### 5.3 官方数据不被迁移或覆盖

本仓**不做数据迁移**：读不到旧目录不删、不迁，官方版 ZCode 的数据保持原样，两个产品在同一台机器上并存互不干扰。详见[数据目录与背景主题契约](data-contracts.md)。

## 6. 本说明书的边界

- 本说明书只描述**当前检出的源码所提供**的功能、命令与文件。
- 涉及状态所有者、事件顺序、失败语义的内容，以 `docs/已完成/` 与 `docs/未完成-` 下的契约文档为准，本说明书只做面向使用者的转述。
- 凡是无法在源码或契约中核实的条目，均标注 `> **待核实**：...`，不用推测填充。
- 上游文档会随版本演进，本说明书的对照基准是改写当时的官方中文站内容。若上游已更新而本页未同步，以本仓源码为准。
