# 命令

命令（Command）用来快速调用 Reactor Agent 的内置能力，也可以保存常用提示词。把重复使用的代码审查、提交说明、发布检查等提示词保存成命令后，就可以在输入框里通过 `/` 快速调用。

本页覆盖：内置命令有哪些、怎么新建自定义命令、自定义命令的存放路径与 frontmatter 字段。

## 在 Reactor Agent 中使用

1. 在输入框输入 `/`，打开命令面板。面板分为 **命令** 和 **技能** 两个分组，可以继续输入关键字筛选。
2. 选择要使用的命令，或继续输入命令名进行筛选。
3. 如果命令需要参数，可以在命令后继续补充路径、模块名或说明。

常用内置命令：

| 命令 | 用途 |
| --- | --- |
| `/goal` | 查看、设置、替换、暂停、恢复或清除当前会话目标，适合持续执行的长任务 |
| `/compact` | 压缩当前对话上下文，保留关键信息，适合长对话继续推进时使用 |
| `/init` | 检查当前工作区并创建或更新工作区根目录的 `AGENTS.md` |
| `/skill` | 不带参数时列出可用技能；带技能名时强制本轮先加载该技能 |
| `/mcp` | 查看或管理 MCP 服务器连接状态 |
| `/plugins` | 打开插件管理面板，或以 `enable` / `disable` 持久切换某个插件 |
| `/model` | 查看或切换当前会话模型 |
| `/effort` | 查看或切换当前会话的推理强度（别名 `/variant`） |
| `/mode` | 查看或切换当前权限模式（`plan` / `build` / `edit` / `yolo`） |
| `/new` | 新建一个空白会话（别名 `/clear`） |
| `/resume` | 恢复历史会话（别名 `/continue`） |
| `/rewind` | 查看或回滚工作区检查点 |
| `/fork` | 从某个工作区检查点分叉出新会话 |
| `/locale` | 查看或切换界面语言（别名 `/language`） |
| `/help` | 查看斜杠命令帮助；`/help <命令名>` 查看单条命令的详细说明 |

> 输入 `/help` 可以列出当前版本的全部斜杠命令与用法；不同界面形态（终端 TUI、桌面端、Web 端）暴露的命令集合略有差异，以 `/help` 的输出为准。

需要调用技能时，使用 `$` 或在 `/` 面板的 **技能** 分组中选择，详见[技能](skill.md)。

## 新建 Command

在设置中进入 **命令** 页面，点击新建命令后填写以下内容：

| 字段 | 说明 |
| --- | --- |
| **作用域** | 选择 **用户**（所有工作区可用）或 **工作区**（仅当前项目可用） |
| **名称** | 命令名称，保存后可通过 `/command-name` 调用 |
| **描述** | 可选，显示在命令选择器中的简短说明 |
| **参数提示** | 可选，用来提示参数格式，例如 `<file-path>` |
| **提示词** | 命令真正发送给 Agent 的提示词内容 |

自定义命令以 `.md` 文件形式保存，保存后在输入框中通过 `/command-name` 即可调用。

## 自定义命令的存放路径

命令文件按作用域从这些根目录发现，同名命令按「先到先得」解析：

| 作用域 | 目录 | 说明 |
| --- | --- | --- |
| 用户级 | `~/.reactor/commands/<命令名>.md` | 所有工作区可用 |
| 用户级 · 兼容 | `~/.agents/commands/<命令名>.md` | 跨工具约定目录，与上面**合并**扫描 |
| 工作区级 | `<仓库>/.zcode/commands/<命令名>.md` | 仅当前项目可用，支持沿 worktree 向上逐层查找 |
| 工作区级 · 兼容 | `<仓库>/.agents/commands/<命令名>.md` | 跨工具约定目录，与上面**合并**扫描 |
| 插件 | 插件包内 `commands/<命令名>.md` | 随插件启停，见[插件](plugin.md) |

命令名取自文件名（子目录会以 `:` 连接），小写化后须匹配 `^[a-z0-9][a-z0-9_:-]{0,63}$`，不合法时该文件会被忽略并给出诊断。

## 命令文件的 frontmatter 字段

`commands/*.md` 的 YAML frontmatter 支持以下字段：

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `description` | ✅ | 命令描述；正文非空时也可省略，Reactor 会取正文首行作为描述 |
| `argument-hint` | | 参数提示，如 `"[topic]"` |
| `allowed-tools` | | 逗号分隔，限制该命令可用的工具 |
| `model` | | 覆盖默认模型 |
| `skills` | | 逗号分隔，自动挂载的技能——Reactor 会在执行命令前要求先加载这些技能 |
| `disable-noninteractive` | | 布尔；为真时该命令在非交互模式下不暴露 |

其余未识别的 frontmatter 字段会作为警告提示，但不影响命令加载。

正文里 `$ARGUMENTS` 代表用户传入的全部参数，`$1` / `$2` 代表位置参数；如果正文里没有使用占位符而用户又传了参数，参数会以「User arguments:」的形式追加到提示词末尾。正文中的 shell 展开语法（`` !`...` `` 或围栏 ` ```! ` 块）当前**不支持**，命中时会直接报错，提示动态展开暂不可用。

一个最小示例：

```md
---
description: 生成本次改动的发版说明
argument-hint: "[版本号]"
---

阅读本次提交记录，按以下结构写一版发版说明：

- 新增
- 修复
- 破坏性变更

版本号：$1
```

## 从外部 Agent 导入命令

如果你已经在 Claude Code 等外部 Agent 中维护了一批命令，不需要在 Reactor 里重新创建。在 **命令** 页面右上角点击 **从外部 Agent 导入命令**，即可把外部 Agent 已有的命令直接导入到 Reactor。

1. 在设置中进入 **命令** 页面。
2. 点击右上角的 **从外部 Agent 导入命令**。
3. 选择要导入的外部 Agent 命令，并选择导入目标（全局或当前项目）与导入方式（复制或软链），确认后即可导入。

导入后的命令和自建命令一样保存在命令列表中，通过 `/command-name` 调用；你也可以在 Reactor 内继续修改名称、描述、参数提示或提示词内容。

## 使用建议

如果只是保存一段简单提示词，使用命令即可；如果流程需要脚本、模板或示例文件，更适合做成[技能](skill.md)。

## 与上游 ZCode 的差异

| 项 | 上游写法 | 本说明书写法 | 原因 |
| --- | --- | --- | --- |
| 产品名 | ZCode | Reactor | 本仓产品名与 rebrand 契约 |
| 用户级命令目录 | 上游 `.zcode/commands` | 改为 `~/.reactor/commands` | 用户数据目录契约 |
| 工作区级目录 | 泛写「项目目录下」 | 明确为 `<仓库>/.zcode/commands/`（工作区级保持 `.zcode`） | 与本仓目录约定一致 |
| 内置命令 | 只列 `/goal` 与 `/compact`，并称「当前内置两个命令」 | 补列本仓实际可用的内置斜杠命令（`/init`、`/skill`、`/mcp`、`/plugins`、`/model`、`/mode`、`/new`、`/resume`、`/rewind`、`/fork` 等），并提示以 `/help` 为准 | 上游只介绍面向长任务的子集，本仓实际命令集更大 |
| 账号与套餐类命令 | 上游含登录/套餐相关命令 | 未收录 | 内网部署不涉及上游账号与套餐 |
| 外部 Agent 导入 | 泛写「Claude Code 等」 | 保留能力，举例收敛为 Claude Code | 只保留可确认的导入来源 |
| 下一步/相关链接 | 站内链接指向官方文档站 | 改为本说明书相对链接 | 离线站点，不请求外部资源 |
