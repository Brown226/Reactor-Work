# 概述与核心能力

**Reactor（数智堆脑）** 是面向内网环境部署的 Agentic Development Environment（ADE）：把大模型的长上下文与长程任务能力，落到桌面端、Web 端与终端里可连续推进的开发工作流上。

本页说明 Reactor 的定位、核心能力与上手路径。如果你是第一次接触，读完本页后按[安装与部署](install.md)、[接入模型](model-access.md)把环境跑起来即可。

## Reactor 是什么

Reactor 由上游 ZCode 二次开发而来：保留 Agent 工作流、任务与文件管理、扩展体系等主体能力，替换掉面向公网的登录、模型网关、插件市场与社群链路，改为接入**内网自建服务端**。

它在一个任务里同时持有目标、文件、终端结果、浏览器上下文、执行模式与 Git 状态，让复杂开发任务从规划一路推进到实现与验证收口，不因步骤切换而丢失连续性。

通过自然语言指令，你可以让 Reactor Agent 处理编码、调试、测试、项目预览和变更审查等工作；也可以在长任务执行过程中持续查看进度并补充指令。

## 核心能力

- **长任务执行**：在同一个任务里完成需求理解、计划拆解、代码修改、验证与审查，减少频繁切换上下文带来的中断。
- **稳定上下文保持**：持续读取文件、终端、浏览器、执行模式与 Git 状态，支撑长程任务的连续推理。
- **自研 Agent 工作流**：任务、权限、上下文、工具调用与提交流都围绕 Reactor Agent 组织，模型输出能自然落到实际工程操作上。
- **多端跟进**：桌面端、Web 端与终端共用同一套会话运行时；手机远控接入桌面已有会话，不另起 Agent。
- **企业模型治理**：企业登录状态下，可选的模型由内网服务端目录决定，模型调用统一走内网网关并可按人归属。
- **安全可控**：关键命令、文件修改和高权限操作会在执行前进入确认流程，权限模式可配置。

## 上手路径

1. **准备环境**：按[安装与部署](install.md)准备仓库与运行时依赖，选择桌面端、Web 端或命令行版启动。
2. **接入模型**：按[接入模型](model-access.md)配置企业服务端地址并登录，确认聊天里能选到企业模型。
3. **跑通一次任务**：打开一个项目目录作为工作区，输入一句简单指令（例如让 Agent 列出当前目录的文件），确认响应正常。
4. **日常使用**：重点看[Reactor Agent](agent.md)的补充上下文与执行模式，以及[快捷键表](keyboard-shortcuts.md)。
5. **遇到问题**：按[反馈与支持](feedback.md)通过内网渠道提交工单。

## 称谓与路径口径

阅读本说明书时，以下口径在全篇一致：

| 项 | 本说明书口径 | 说明 |
| --- | --- | --- |
| 产品名 | Reactor；需要全称时用 Reactor（数智堆脑） | 协议名、包名（如 `@zcode/shared`）与 `zcode` 命令名保留原名 |
| 用户级目录 | `~/.reactor` | 会话、凭据、用户级技能 / 命令 / 子智能体、CLI 日志等 |
| 工作区级目录 | `<项目根>/.zcode` | 项目配置的产品语义，保持原名 |
| 跨工具目录 | `~/.agents`、`~/.claude` | 跨工具约定目录，保持原名 |
| 环境变量 | `ZCODE_*` | 如 `ZCODE_DATA_BASE_DIR`、`ZCODE_HOME`，保持原名 |

用户级目录可用环境变量覆盖（优先级高于内置值）：`ZCODE_DATA_BASE_DIR` 指定数据基目录（用户数据根 = 其下的 `.reactor/`），`ZCODE_HOME` 直接指定用户数据根。详见[数据目录与背景主题契约](data-contracts.md)。

## 与上游 ZCode 的差异

- 上游写法：产品名 ZCode，围绕公网模型讲定位。→ 本说明书写法：产品名 Reactor（数智堆脑），定位为内网隔离部署的 ADE。→ 原因：本仓已完成品牌与部署形态调整。
- 上游写法：大篇幅介绍公网套餐权益、免费体验与额度机制。→ 本说明书写法：全部删除，改为内网模型网关接入。→ 原因：内网部署无公网计费与套餐链路。
- 上游写法：把机器人渠道与手机远控并列作为多端入口。→ 本说明书写法：不收录机器人渠道，只写桌面、Web / 终端与手机远控。→ 原因：本仓未提供该能力。
- 上游写法：结尾列出社交通道与交流群。→ 本说明书写法：删除，反馈改为内网受理（见[反馈与支持](feedback.md)）。→ 原因：该类入口与公网账号绑定。
- 上游写法：用户级数据目录写作旧名。→ 本说明书写法：用户级为 `~/.reactor`，工作区级 `.zcode` 不变。→ 原因：本仓用户级目录已收口为 `USER_DATA_DIR_NAME` 常量。
