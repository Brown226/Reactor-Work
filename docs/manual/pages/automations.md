# 定时任务

有些工作不需要你每次亲自发起：每天早上汇总代码变更、每周五整理发布简报、每月检查一次依赖风险。**定时任务** 让 Reactor Agent 按你设定的节奏自己跑起来，跑完把结果留在会话里等你查看。

自动化下面有两类任务：

- 定时任务（Scheduled tasks）：你指定时间和重复规则，到点自动执行。本页介绍。
- [闲时任务](idle-time-tasks.md)：不指定时间，排队等算力富余时由内网服务端放行执行。

在左侧边栏点击 **自动化** 即可打开管理页面。它属于当前项目的工作流，不在设置里——打开它不会影响左侧的会话列表，随时可以退回原来的会话。

> **提示**：自动化页面同时承载定时任务与闲时任务两个标签；两者共用刷新、状态筛选与「保持电脑运行」开关。

## 创建定时任务

有三种方式，效果一致，选顺手的即可。

### 用表单创建

在自动化页面点击 **创建定时任务**，填写三样东西：

| 字段 | 说明 |
| --- | --- |
| **任务标题** | 用于在列表和历史里识别这个任务 |
| **执行计划** | 什么时候跑、多久跑一次，见下文「调度规则」 |
| **指令** | 每次触发时发给 Agent 的内容，写清楚要做什么、产出什么 |

指令输入框下方的工具条决定这个任务以什么身份、什么能力执行，见下文「任务配置」。

### 在会话里创建

点击创建按钮右侧的箭头，选择 **去会话中创建**，输入框会预填一句示例，你可以直接改成自己的需求，例如：

```text
每个工作日 9 点，汇总当前项目的代码变更和待跟进事项。
```

也可以在会话里直接让 Agent 建这个任务，包括指定运行次数等表单里没有的细节。

用这种方式创建的任务会 **绑定到当前会话**：后续每次触发都把结果投递回同一个会话，而不是每次新开一个。适合希望所有产出集中在一处的场景。创建成功后，会话里会出现一张任务卡片，点击「去到定时任务」可以直接跳到它的详情。

### 从模板创建

自动化首页提供现成模板，点击即可预填完整指令，改改就能用。模板由内网服务端下发，按场景（如晨会动态、风险扫描、发布简报、文档同步检查）分类；服务端未配置模板时，该区块显示「无可用模板」。

这些模板都遵循同一套约束：只做只读分析、只使用可验证的仓库事实、证据不足时明确说明，不推测，也不修改代码。

## 调度规则

在执行计划里选择频率：**每小时 / 每天 / 每工作日 / 每周 / 每月 / 自定义**。

选择「自定义」会打开重复规则对话框，可以组合出更细的节奏：

| 维度 | 可选值 |
| --- | --- |
| **重复单位** | 分钟、小时、天、周、月、年 |
| **间隔** | 每 N 个单位执行一次，例如「每 2 小时」「每 3 天」；取值范围 1–200 |
| **具体时点** | 周几、每月几号、几月份，以及具体的时和分 |
| **按日期或按星期** | 每月重复时，可选「每月 15 号」或「每月第三个周一」 |

确认后，调度栏会收起成一句简短摘要（如「每 2 小时的第 30 分」），点击摘要可以再次编辑。周几、每月几号这类选择在表单里直接以胶囊标签呈现，改完立刻反映到摘要里。

### 什么时候停下来

定时任务默认无限重复。希望它到某个日期后自动停止，可以在自定义重复对话框的 **结束** 一栏选 **指定日期**；到期后任务进入「已完成」状态，不再触发。不设结束日期时对应「永不结束」。

界面上没有「最多跑几次」这个选项。确实需要限定次数时，可以在会话里让 Agent 帮你建这个定时任务，直接说明跑几次就行。

> **关于时间**：所有时间都按你电脑的本地时区计算，时间选择器旁会标注当前 GMT 偏移。任务卡片上会显示下次运行时间——一个月以内显示相对时间（如「3 天后」），超过一个月显示具体日期。

## 任务配置

指令输入框下方的工具条决定这个任务以什么身份、什么能力执行：

- 项目：任务在哪个项目目录下运行。只能选当前窗口已打开的本地项目，创建后不可修改。
- 权限：和会话里一样的四档执行模式，决定 Agent 能不能自己动手改文件、跑命令。默认「变更前确认」；选了「完全访问」时界面会一直留一个提醒。
- 模型：指定执行时使用的模型，默认跟随当前项目首选模型。
- 推理强度：控制思考深度，随模型能力呈现。

因为定时任务在你不盯着的时候执行，权限选择尤其值得斟酌——需要 Agent 自主改代码就放开权限，只想要一份分析报告就保持只读。

> **注意**：Agent 可通过会话内工具修改定时任务的调度，此时该任务的调度字段会标记为「由用户显式编辑过」，管理页不再按会话来源做只读保护。

## 管理与运行

### 立即运行

任务卡片菜单与编辑页里的 **立即运行** 会马上执行一次。它不打乱原本的计划——下次运行时间、已运行次数、启停状态都不会因此改变，手动触发只累加展示用的运行次数。

如果上一次触发还没跑完，重复点击不会排第二条，界面会提示「上一条正在运行中，请稍后再试」。

### 暂停、编辑与删除

任务有四种状态：**运行中、已暂停、已完成、已失败**。

| 状态 | 说明 |
| --- | --- |
| 运行中 | 已启用并会按计划触发 |
| 已暂停 | 保留任务但不再触发，可随时 **继续** |
| 已完成 | 到达结束日期或运行次数上限，不再触发 |
| 已失败 | 最近一次派发或运行失败，可 **重新启动** |

暂停后任务保留但不再触发，卡片上的执行时间与运行次数会弱化显示。删除任务前会弹出确认，并说明该操作无法撤销。

编辑时如果有未保存的改动，返回前会提示你确认是否丢弃。

### 运行历史

任务详情页顶部可以在 **设置 / 历史** 之间切换。历史里记录每一次触发的结果，包括执行中、成功、失败、已停止，以及因为电脑未唤醒而 **跳过** 的那些。有对应会话的记录可以直接跳转过去查看当时发生了什么，也可以删除单条记录。历史记录按页浏览。

### 列表筛选

任务列表顶部提供状态筛选：**全部 / 进行中 / 已完成 / 失败**。切换标签页时筛选会自动回到「全部」。筛选口径以卡片上实际显示的状态为准——循环任务只要最近一次运行失败，就会归入「失败」。

## 需要注意的限制

**电脑必须是唤醒状态。** 定时任务在你的电脑上执行，机器睡眠或应用未启动时不会触发，错过的一次性任务会记为跳过而不是补跑。如果任务安排在夜间或午休时段，请在自动化页面打开 **保持电脑运行** 开关——这是一个全局开关，定时任务和闲时任务共用，也可以在「设置 → 保持电脑运行」里修改。

**最多 20 条。** 这是本地任务索引允许保留的定时任务定义总数，暂停、已完成、失败的任务同样占用名额，只有删除任务定义才会释放。达到上限时新建会被拦下，需要先去清理不再需要的任务。在会话里让 Agent 创建时如果撞上上限，它会直接告诉你并停下，不会自作主张删掉你已有的任务。

**只支持本地项目。** 新建任务时只能选当前窗口打开的本地项目，远程工作区不在支持范围内。手机端远程控制界面不显示自动化。

> **待核实**：上游文档说明「已有的远程任务仍可查看和管理」，本说明书未回源码核对远程工作区上已存在定时任务的可见性；以当前版本实际界面为准。
