# 任务与文件管理

随着任务越积越多，左侧边栏提供了几个高频管理能力：**任务视图** 让你按分组、项目或时间线组织任务列表，**工作区文件树** 让你不离开 Reactor 就能浏览文件、查看变更并把文件引用进对话，**仓库百科** 则把整个仓库的结构整理成一份随时可查的文档。

## 任务视图

左侧任务栏顶部的视图菜单提供三种组织方式，可以随时切换。

- 分组：按自定义分组归类任务，适合按主题或优先级整理。
- 按项目：任务跟着项目走，每个项目下平铺它的任务。
- 时间线：按时间倒序排列，找最近做过的事最快。

视图菜单旁边还有几个常用入口：

- 排序方式：在视图菜单里选择，按 创建时间 或 更新时间 排列任务。
- 搜索：点击放大镜图标，可以按关键词搜索任务。
- 归档：点击归档图标进入归档列表，再次点击退出。

## 归档任务

已完成、无未读、未置顶且超过保留期的任务会进入自动归档候选。归档保留时长可在「设置 → 自动归档旧任务」里选择 **3 / 7 / 14 / 30 天**，超过该时长未更新的任务才会进入候选；自动归档总开关也可以单独关闭。

归档列表里每条任务右侧提供两项操作：

| 操作 | 说明 |
| --- | --- |
| 取消归档 | 任务恢复到普通任务列表 |
| 删除 | 永久删除该任务 |

> **提示**：归档列表支持批量删除。删除前会先显示将要删除的任务数量，结果里分别报告已删除、跳过与失败的数量。

## 任务分组

切换到 **分组** 视图，即可按自定义分组组织任务。

### 创建与管理分组

1. 点击 **新建分组**，输入分组名称。
2. 点击分组标题右侧的颜色点，可在 7 种颜色（灰 / 红 / 橙 / 黄 / 绿 / 蓝 / 紫）中选择，用颜色区分项目或优先级。
3. 单击分组标题可随时 **重命名**。
4. 右键分组可选择 **取消分组并删除**——只删除分组本身，组内任务会保留并移出分组。

分组本身按工作区归属；打开不同项目时看到的是该项目的分组。

### 整理任务

- 拖拽：直接把任务拖进目标分组，也可以在组内拖拽排序、拖动分组标题调整分组顺序。
- 右键菜单：在任务上右键选择 移动到分组 / 移出分组，不方便拖拽时同样高效。
- 移动到顶部：组内任务较多时，右键选择 移动到顶部 比一路拖上去快得多。
- 空分组：直接拖任务到空分组的投放区，或在该处新建任务。
- 折叠与展开：点击分组标题左侧的三角形折叠单个分组，或用列表顶部按钮全部展开 / 收起。

## 快捷入口

侧边栏顶部的搜索框不只用来找任务。点开后会列出 **快捷入口**：新任务、打开工作区、搜索文件、切换主题、MCP 服务器、切换终端等常用操作都能在这里直接执行，旁边标注了对应的快捷键，熟悉之后基本不用碰鼠标。快捷入口与快捷键的完整列表见 [快捷键表](keyboard-shortcuts.md)。

## 工作区文件树

点击工作区卡片右侧的 **文件树图标**（查看文件），左侧边栏会切换为当前工作区的文件树；点击顶部 **返回任务** 即可切回任务列表。

### 浏览与搜索

- 搜索文件：顶部搜索框支持按文件名或路径实时筛选。
- 仅显示变更文件：一键过滤出有 Git 变更的文件，代码评审或提交前检查特别好用。
- Git 状态标识：文件右侧会显示 Git 状态标记（新增 / 修改 / 删除 / 重命名 / 未跟踪 / 已忽略），目录上会聚合显示内部变更状态点。
- 刷新：文件树右上角提供刷新入口，重新读取当前目录。
- 吸顶目录：目录层级较深时，滚动过程中父目录会吸顶显示，方便随时定位。

### 打开与引用

- 单击文件即可在右侧打开预览；双击或按 Enter 用默认编辑器打开。
- 拖拽到对话框：把文件直接拖进对话输入框，自动插入文件引用，让 Agent 围绕该文件工作。
- 右键菜单：打开 / 打开方式（选择已安装的编辑器）/ 添加到聊天 / 复制绝对路径 / 复制相对路径 / 用内置浏览器打开（HTML 文件）/ 在资源管理器中打开。
- 文件树标题右侧的更多菜单可以打开工作区所在目录，或复制工作区路径。

> **提示**：「仅显示变更文件」+「添加到聊天」组合使用，可以快速把本次改动的文件喂给 Agent 做自查或生成提交说明。

### 仓库百科

文件树顶部、仓库名称旁的 **仓库百科** 图标，会基于当前仓库生成一份架构导读：讲清楚这个项目是干什么的、主流程怎么跑、有哪些核心模块、数据怎么流动，每个结论都能点回源码。接手陌生项目时特别有用。完整说明见 [仓库百科](repo-wiki.md)。

### Git 图谱

工作区顶部的分支切换器下拉里还有一个 **Git 图谱** 入口，打开后是一张只读的提交历史图：分支并排画出，合并发生在哪里一目了然，适合理清「这个分支是从哪儿分出去的」「这两条线什么时候合的」。

点击某个提交会在旁边显示它的标题、完整哈希、作者、日期和父提交。默认先加载最近的一批，点「加载更多提交」继续往前翻。

它只负责看：**不能在图里切换分支，也不能查看具体改动内容**。切换分支、新建分支在同一个下拉菜单的上半部分——如果切换时有未提交的改动，Reactor 会提示你先提交，也可以直接选择「提交并切换分支」。

## 与上游 ZCode 的差异

| 项 | 上游写法 | 本说明书写法 | 原因 |
| --- | --- | --- | --- |
| 产品名 | ZCode | Reactor（数智堆脑） | 本仓品牌为 Reactor |
| 任务视图第二项 | 工作区 | 按项目 | 与界面菜单文案「按项目」对齐 |
| 文档标题 | 仓库 Wiki | 仓库百科 | 与界面入口文案对齐 |
| 站内链接 | `/cn/docs/*` 绝对路径 | 相对 `.md` 链接 | 离线站点，构建自动改写为 `.html` |
| 归档保留期 | 3 / 7 / 14 / 30 天 | 保留 | 与设置项选项一致 |

> **待核实**：自动归档候选的完整判定链（「已完成、无未读、未置顶且超过保留期」）取自上游描述，本说明书未逐条回源码核对；以本仓「设置 → 自动归档旧任务」与实际归档行为为准。
