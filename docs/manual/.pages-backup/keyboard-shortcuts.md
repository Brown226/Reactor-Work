# 快捷键表

Reactor 的快捷键不是写死在界面里的散点，而是由一张**命令表**统一定义、可由用户改绑的配置项。本页列出默认键位与改绑方式。

## 1. 唯一数据源

快捷键命令表位于 `packages/shared/src/shortcutCommands.ts`，是全仓库快捷键的**唯一事实来源**：

| 约束 | 含义 |
| --- | --- |
| 纯数据 | 该文件只含数据与纯函数，不依赖 DOM / Electron，供主进程、渲染进程与服务共用 |
| 一处收敛 | 键位知识只允许定义在这里；设置页、菜单、键盘分发都不得自行解析键位 |
| 同形复用 | 绑定字符串同时用于持久化、渲染进程匹配与桌面菜单 accelerator 透传 |

命令有两个通道与两个作用域：

| 分类 | 取值 | 说明 |
| --- | --- | --- |
| 通道 `channel` | `window` | 渲染进程键盘分发，桌面 / Web / 终端三端一致 |
| 通道 `channel` | `menu` | 桌面应用菜单 accelerator |
| 作用域 `scope` | `global`（缺省） | 全局分发 |
| 作用域 `scope` | `composer` | 仅在聊天输入框聚焦时消费，Enter 族键因此可以安全入表 |

| 命令 | 默认绑定 |
| --- | --- |
| 新建任务 | `CmdOrCtrl+N` |

| 关闭当前上下文 | `CmdOrCtrl+W` |

> **提示**：「切换编程 / 办公模式」的命令已在命令表中注册，但**当前没有执行侧**，按下不会生效。
> 界面模式请从主面板的胶囊分段控件切换，详见[界面模式](interface-modes.md)。

> 早期原型曾把两者标混，以命令表为准。

## 3. 改绑与冲突处理

在**设置 → 键盘快捷键**里可以搜索、录制、恢复默认：

| 操作 | 行为 |
| --- | --- |
| 录制 | 按下新组合即可；`Esc` 取消，`Backspace` 恢复默认，冲突后直接重按新组合 |
| 搜索 | 可按命令名搜索，也可直接按下组合键反向搜索 |
| 恢复默认 | 支持逐条恢复，也支持「全部恢复默认」 |
| 作用域列 | 区分「全局」与「输入框」两类命令 |

冲突与校验规则：

| 情况 | 提示 |
| --- | --- |
| 组合键被系统占用 | 「该组合为系统保留键位」，拒绝绑定 |
| 组合键已被其他命令占用 | 提示占用者；可选择「仍要绑定（原命令将失效）」 |
| 缺少修饰键 | 「至少需要一个修饰键（Ctrl / Cmd / Alt）」 |
| 不支持的按键 | 「不支持的按键」 |
| 重复绑定到同一命令 | 「该组合已绑定到此命令」 |

绑定串有规范形式：修饰键顺序固定为 `CmdOrCtrl`、`Ctrl`、`Alt`、`Shift`、`AltGr`，键名须为规范形式（小写字母、数字或白名单命名键）。修饰键顺序不敏感，但重复修饰键、大写字母、裸 `+`（需写 `=`）与未知命名键都会判定为非法绑定。

## 4. 与上游 ZCode 的差异

| 项 | 上游写法 | 本说明书写法 | 原因 |
| --- | --- | --- | --- |
| 界面模式快捷键 | 上游的界面模式切换在草稿态以胶囊分段控件提供，未把改绑入口列入快捷键表 | 明确写出该命令**已注册但无执行侧** | 本仓命令表存在该条目，但实际不可用；如实标注避免用户误以为可通过快捷键切换 |
| 快捷键设置 | 上游文档称可录制自定义按键并即时生效 | 保留该表述，并补齐本仓的冲突规则与绑定串规范 | 本仓 `shortcutCommands.ts` 是唯一数据源，规则可从源码核实 |
| 命令清单 | — | 按本仓命令表逐条列出，含双默认绑定与显式 `Ctrl` 修饰说明 | 上游文档未列出完整默认键位 |
