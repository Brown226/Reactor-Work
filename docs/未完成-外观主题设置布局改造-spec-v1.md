# 外观 → 主题设置布局改造（对齐 NewMax 偏好面板）

## 背景

当前 Reactor 的「外观 → 背景主题」是 3 列矩形卡片网格 + 独立的参数卡片，视觉上偏「表单 + 缩略图」。
NewMax 的偏好面板用另一种组织方式：壁纸是**一横排竖向胶囊卡片**、可调参数是**三栏并排小卡**、
强调色是**圆形色块 + 名称 + 描述的两列清单**。

产品要求：吸收 NewMax 的**布局与视觉组织**，不照搬它的功能项（它多出来的「随机配色 / 纯度 / 对比度 /
对话字体」在 Reactor 没有对应状态，不新增）。

## 只改布局，不改数据模型

以下保持原样，不新增 store 切片、不改持久化键：

- `backgroundTheme`：`presetId / imagePath / blurPx / scrimPercent / motion`
- `accentColor`：`presetId`
- 背景预置清单（5 渐变 + 6 风景）与自定义图片上传

## 布局变更

### 1. 壁纸选择：3 列网格 → 横排竖向胶囊

- 容器 `flex gap-2 overflow-x-auto`
- 单卡 88×120px、`rounded-2xl`、`overflow-hidden`
- 选中态：`ring-2 ring-brand` + 右上角实心勾选圆点（`CheckIcon`）
- 名称压在底部渐变遮罩上（位图族），渐变族用弱化文字
- 「不使用背景」为虚线边框卡片；「上传图片」为图标卡片，排在最末
- 横向滚动对 12 个预置是必要的：`max-w-4xl`（896px）内放不下 12 个 88px 卡片

### 2. 参数区：纵向 SettingsRow → 三栏并排小卡

- 小标题「显示效果」
- 三张等宽小卡（`grid grid-cols-1 sm:grid-cols-3 gap-2`）：模糊 / 覆盖色 / 动态壁纸
- 每张卡：标题 + 右上角数值 + 下方控件
- 动态壁纸是开关，卡片内右对齐

### 3. 强调色：并入「颜色主题」两列清单

- 小标题「颜色主题」
- `grid grid-cols-1 sm:grid-cols-2 gap-x-4 gap-y-1`
- 每项：28px 圆形色块 + 名称 + 描述
- 色块用**身份色**（中等饱和），不是原来的浅色档——原来的 `#e6f4fa` 在深色卡片上近乎白色，用户无法分辨档位差异，这就是"点了没反应"的直接观感来源

## 强调色为什么"点了没反应"

核验结论（不是推测）：

1. 状态链是通的：`setAccentColor` → `localStorage` → `applyAccentColor` → 文档根 `data-app-accent` + 两个 CSS 变量 → `styles.css:65-70` 覆盖 `--color-accent`。特异性 `:root[data-app-accent]`(0,2,0) 高于 `@theme` 的 `:root`(0,1,0)，覆盖有效。
2. 真正的问题是**感知面太窄**：`--color-accent` 在仓库里只被 `bg-accent` 消费十余处（下拉项 hover、拖拽遮罩、查找高亮），且大多是低强度半透明块。用户点完色块，设置页本身没有任何可视反馈。
3. 次要问题：色块用 `getAccentPresetColor(id, "light")` 绘制，深色主题下是近白色圆点，档位之间几乎看不出差别。

修复：选中态加环 + 勾、色块改用身份色、文案写清作用面。

## 验收

- 外观页在 `max-w-4xl` 下：壁纸横排可滚动、三栏参数卡在 640px 以上并排、颜色主题两列
- 切换任一强调色：设置页色块选中态立即变化；描述文案说明"影响选中/高亮块"
- 切换背景预置：主内容区背景变化、设置页缩略图选中态跟随
- 深浅主题下色块都能分辨档位

## 不做的

- 不新增「随机配色 / 纯度 / 对比度 / 对话字体」（Reactor 无对应状态，属功能照搬）
- 不改 `--color-brand`（DESIGN.md 品牌色约束）
- 不改 `backgroundTheme` / `accentColor` 的持久化与跨窗口广播
