# 研究插件 · 方案 v1

状态：待实施｜适用范围：内网/公网部署｜维护者：桌面工具组

## 1. 背景与目标

产品此前没有任何研究/检索类插件技能：文献调研、量化分析、对比评测、根因排查、消融
实验、论文复现、引用校验这类「有量级、要纪律」的自主研究工作没有对应能力。本方案
从 mimocode 内置包（`builtin_skills/desktop-1579e7d`）引入两个技能，成立独立内置
插件 `research`，随安装包分发、离线可用（脚本仅依赖 Python stdlib + 免费学术 API，
无需 API key）。

## 2. 目标形态

纯内容型插件（无 package.json、不进 pnpm workspace），对齐四件套 fork 形态：

```
apps/zcode-cli/packages/research-plugin/
  .zcode-plugin/plugin.json        插件清单（version 0.1.0）
  LICENSE.txt                      来源与授权说明（书面许可）
  README.md                        插件说明
  skills/
    super-research/                8 模式自主研究路由（SKILL.md + references/ + evals/ + scripts/）
    arxiv/                         论文级工具belt（检索 / BibTeX / 下载 / 引用图谱）
```

## 3. 产品规则（边界）

| 规则 | 内容 |
| --- | --- |
| 职责划分 | `super-research` 是**研究方法与纪律的路由器**（契约 → 基线 → TSV 日志 → 不停机循环 → 报告）；`arxiv` 是**论文级操作工具belt**（单篇元数据、BibTeX、PDF、分类日报、 cites/refs/similar） |
| 检索重叠的唯一 owner | 多源检索（arXiv+S2+OpenAlex+Crossref 去重）归 `super-research/scripts/paper_search.py`；arXiv 单源的深度操作（bibtex/download/new/cites/refs/similar）归 `arxiv/scripts/arxiv.py`。两者不互相替代 |
| 与 zcode-guide 的分工 | zcode-guide 只回答「ZCode 自身怎么用」；本插件回答「把研究做完」。触发词不交叉 |
| 与 review-skills 的分工 | review-skills 审代码与文档一致性；本插件的 root-cause/ablation 模式面向研究与实验对象，不改 review 的射程 |
| 零依赖约束 | 脚本必须保持 stdlib-only + 免费 API、无 key；新增脚本违反此约束需先改本 spec |

## 4. 授权与许可登记

上游作者已给予**书面复制许可**（2026-10-09，许可件由项目所有者持有）。登记口径：

- `third-party/copied-components.json` 新增一条 record（无上游 LICENSE 文件，走
  `reviewRequired` 说明许可来源与状态）；
- 插件根 `LICENSE.txt` 记录来源、许可性质与「随产品分发」事实；
- `arxiv` 技能 frontmatter 自带 MIT 声明，原样保留；`super-research` 无许可声明，
  以书面许可为准。

## 6. 验收场景

1. `research` 插件可被发现，2 个 skill 可见（断网启动不报错——脚本按需联网）。
2. 冒烟：`paper_search.py` / `verify_citation.py` / `fetch_paper.py` / `arxiv.py`
   `--help` 可执行；有网环境下各跑一条真实查询。
3. `pnpm typecheck` / `pnpm lint` / `pnpm architecture:check --changed` 通过
   （本次改动含 bootstrap 与 cli，按跨包口径全量执行）。
4. `node scripts/licenses.mjs notices` 生成的 NOTICES 含新条目（本机 EMFILE 时按
   四件套 spec 8.3 的手工同步口径执行并自校验）。
