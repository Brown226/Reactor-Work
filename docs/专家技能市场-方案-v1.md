## 0. 一句话目标

企业登录用户在「专家·技能」市场页里**浏览、搜索、分类筛选服务端下发的专家与技能，安装/启停/卸载一键完成**；「我的」视图管理本地全部技能（含吃灰/问题诊断）；全程复用 P2/P3 已建的同步与物化链路，安装关系以服务端为唯一真相。

### 功能汇总（按用户可见能力）

1. 市场浏览：网格卡片、分类、搜索、排序（综合/最热/最新）。
2. 安装生命周期：安装 / 卸载 / 启停 / 收藏 / 更新（有新版本时）。
3. 我的视图：已安装管理、来源与状态筛选、启用开关。
4. 详情弹层：点击卡片弹出介绍弹层——头部（头像/名称/作者/使用次数）、简介、标签、动作（安装/召唤）、示例提示词、基本信息（按截图 4/5 内容块）。
5. 统计与诊断：数量统计、活跃/吃灰、问题检测（截断/缺描述/残留）、上下文占用估算。
6. 分组能力：技能「套件」（截图 7）、专家「专家团/精选场景」（截图 4 背景）。
7. 创建/导入：`添加技能` / `创建 Skill`。
8. 不做：`Skill 激活码`（服务端无此概念）、「连接器」视图。

| 技能分类                     | admin `skill-categories` + catalog 侧分类字段                            | ✅（字典读取面待确认 `/me` 侧，见 §7-U2）                                             |
| 套件（bundles）              | admin `bundles` CRUD + `SkillBundleSummary/Detail`                       | ⚠️ 数据面已有；**`/me` 下发接口待确认**（§7-U2）                                      |
| 专家团                       | —                                                                        | ❌ 无任何 API（§7-U3）                                                                |
| 触发统计（45 天/最后触发）   | `use` 上报有，**无查询接口**                                             | ❌ 数据源缺口（§7-U1）                                                                |

### 客户端已建能力（P2/P3 成果直接复用）

- 技能：`IServerSkillSyncService`（落盘/卸载/更新）、`skillsService` 发现（scope=server）、设置·技能区。
- 专家：`IServerAgentSyncService`（物化/安装/卸载/启停 + 目录投影）、subagents 发现（scope=server）、设置·子智能体「服务端目录」。
- **安装关系唯一真相在服务端；物化目录唯一写者是同步器**——市场页只发命令、读投影，不新增状态（沿 P2/P3 状态所有者表）。

### 插件市场组件（截图 1 的「插件市场」现成实现）

`PluginStorePage`（592 行）/ `PluginStoreListView`（543）/ `PluginStoreCard`（358）/ `PluginStoreDetailView`（492）/ `PluginStoreAvatar` + `pluginStoreListing` 投影 + `usePluginStoreOrder`。约 2000 行成熟市场 UI，但**与插件数据模型强耦合**（Store Listing / plugin.json / marketplace 概念，见 CONTEXT.md）。

## 3. 复用 vs 新建（决策）

**决策：抽壳新建 `packages/ui/src/marketplace/`，插件市场 v1 不动。**

| 项                                           | 处理                                                                                                                                                       | 理由                                                                                                               |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 页面壳（视图切换/搜索/分类 chips/网格/排序） | **新建** `market/` 共享件：`MarketShell`、`MarketTabs`、`MarketCategoryChips`、`MarketSearchBar`、`MarketGrid`                                             | 专家/技能/插件三域共用壳；直接参数化 `PluginStore*` 会牵动插件市场回归面，违背「一个状态一个所有者」的最小改动原则 |
| 卡片/详情                                    | **新建变体**（`ExpertMarketCard`、`SkillMarketCard`、对应 Detail），**复用** `PluginStoreAvatar`、listing 投影写法、`usePluginStoreOrder` 的排序持久化模式 | 字段与生命周期不同（专家有 persona/starters/模型；技能有 SKILL.md/附件），硬统一会造出第二套 manifest 抽象         |
| 插件市场                                     | **不动**；后置把它迁移到共享壳（记为 M3 可选）                                                                                                             | 风险隔离                                                                                                           |
| 动作链路                                     | **复用** P2/P3 同步器与 `skillsService`（不新建安装服务）                                                                                                  | One path：安装/卸载/启停只有同步器/服务端 API 一条写路径                                                           |

**词汇纪律**：实施前在 [CONTEXT.md](../CONTEXT.md) 增补「专家（Expert）/ 专家团 / 套件（Bundle）/ 我的视图 / 吃灰」等术语，避免与插件商店词汇混淆。

- **入口与设置页关系（2026-09-22 追加决策）**：**技能管理迁入本页「我的·技能」**（嵌入原设置技能面板本体 `PluginsSection mode="skill"`）、**子智能体管理迁入本页「我的·专家」**（嵌入 `SubagentsSection`，自带范围切换/搜索/新建/企业专家目录）；设置页「技能」「子智能体」两个分区**均移除**，命令面板「技能」入口改道本页，子智能体表单的「管理模型」经 section intent 跳设置·模型分区（治理隐藏时自动回落）。插件分区内的技能 tab 属插件管理，不动。

## 6. 分期与验收

### M1 市场可用（浏览 + 安装闭环 + 介绍弹层）

1. 菜单出现「专家·技能」（插件市场上方），进入市场页。
2. 专家/技能切换；专家市场卡、分类、搜索、综合/最热/最新生效。
3. 技能市场卡、分类、精选区；安装/卸载/启停/收藏全部走服务端，物化文件随同步器增删（与 P2/P3 验收同语义）。
4. 点击卡片弹出介绍弹层：头部/简介/标签/动作/基本信息与数据一致；专家「专家帮你做」示例点击**预填**新会话（不自动发送）；`Esc`/遮罩/✕ 均可关闭且列表状态保留。
5. 「我的」最小版：已安装清单 + 启用开关（技能）。
6. 未登录企业服务端：市场页展示登录引导，不出现空假象；用户自建技能/agent 不受任何影响。
7. `pnpm typecheck` / `pnpm lint` / `pnpm architecture:check --changed` 通过；明暗主题 + 弹层截图留档。

### M2 详情扩展 + 管理全量

1. `⤳ 召唤专家`：「以此专家开会话」薄封装（应用 model + persona 附注，P3 §4.4 语义）。
2. 技能弹层扩展：SKILL.md 预览、附件清单、版本；「试试这样用」示例词（字段就绪后）预填。
3. 我的·技能管理：统计卡（全部/活跃或未触发降级展示/启用/未启用/有问题）+ 上下文占用估算 + 来源/状态筛选 + 表格（安装位置/工作区/启用开关）。
4. 问题检测：截断（frontmatter 解析失败）/缺描述/残留（目录无 SKILL.md）可复现造出并被标出。

### M3 长尾

弹层「使用案例」块（待服务端字段）、套件整套安装（待 §7-U2 确认）、触发统计与吃灰（待 §7-U1）、一键整理、`添加技能/创建 Skill` 入口收敛、插件市场迁共享壳（可选）。
