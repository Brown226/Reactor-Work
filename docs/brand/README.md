# Reactor 品牌素材

Reactor（中文名「数智堆脑」）的品牌视觉素材。本目录是**设计参考与源素材**，供生成各平台生产资产使用；生产资产按下方清单派生到各自位置，不直接引用本目录文件。

| --- | --- | --- |
| `logo-cube.jpg` | 2977×1280 | 字标组合：白色「Reactor」+ 细分隔线 + 「数智堆脑」，蓝色渐变底 |
| `mark-pinwheel-full.jpg` | 1280×1280 | 风车标记·完整态：八片叶轮，叶片分深蓝/青/紫，深蓝八角底盘，中心白点 |
| `mark-pinwheel-idle.jpg` | 1280×1280 | 风车标记·静置态：叶片整体点亮为青→紫的均匀渐变 |
| `mark-pinwheel-active.jpg` | 1280×1280 | 风车标记·激活态：多数叶片压暗为深蓝，仅少数叶片高亮青色带辉光 |
| `mark-pinwheel-matte.jpg` | 1280×1280 | **等距立方体标记**：蓝色立方，面为网格与发光节点（见下方命名问题） |

### 标记语义

风车（叶轮）是主标记，三个状态构成动效语言：

- **idle** 叶片均匀点亮 → 空闲；
- **active** 少数叶片高亮、其余压暗 → 正在工作，可对应转动/处理中；
- **full** 叶片着色各异 → 完整品牌展示。

主标记指向「反应堆／透平叶轮」，与产品名 Reactor 呼应。

## 标记选定（已确认）

**立方体标记为 Reactor 的唯一产品标记**，风车（叶轮）系列素材不使用。

因此下方同名文件的实际内容为准：`mark-pinwheel-matte.jpg` 承载的是立方体标记（文件名与内容不符，属历史命名遗留，不再作为待办）；`mark-pinwheel-*.jpg` 与 `poster-reference.jpg` 为未采用的早期方案，保留仅作存档。

## 命名问题（已澄清）

以下两个文件的**文件名与内容不符**（经图像分析与色板交叉验证）：

1. `logo-cube.jpg` 内容是**字标组合**（Reactor + 数智堆脑），并非立方体。
2. `mark-pinwheel-matte.jpg` 内容是**等距立方体标记**，并非风车。

命名错位不再处理；判定标记归属时以内容为准。
