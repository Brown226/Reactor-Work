## 六、建议摘取清单

### P0 / 建议优先（独立、耦合低、收益明确）

1. **桌面崩溃后手动重启**（能力 1）——有完整用例与实测证据，仅在既有错误边界与 Main 命令链上加点。
2. **会话活动退出确认**（能力 2）——小改动，避免误退出丢任务。
3. **插件界面首帧主题**（能力 3）——插件作者体验缺陷，改动局限 iframe 桥。
4. **UI 三小修**（能力 11）——纯样式/交互，风险最低。
5. **主窗口导航边界**（能力 8）——安全类，先按文档核对本地实现，再决定是否补代码。

### P1 / 推荐但需重贴或单独立项

6. **预装工具链**（能力 7）——全新子系统（下载/签名/事务/UI/构建），工作量大且触及安装包，建议单独立项，不进本轮。
7. **项目目录插件信任**（能力 4）——涉及安全存储与多端协议，需与本地插件架构对齐。

10. **Skill 实时目录**（能力 5）——触及 CLI skill 加载核心，需把本地 `engineering` skill roots 一并回归。

### P2 / 不摘

## 七、执行前置条件与风险

1. **git 协议到 github.com 不通**（`origin` 与 `zai-org` 均 `Connection was reset`），无法 fetch/merge；只能通过 `api.github.com` 的 Trees/Blobs API 逐文件取（本次比对脚本：`.tmp-probe/upstream_diff.py`、`.tmp-probe/upstream_detail.py`、`.tmp-probe/fetch_upstream_docs*.py`；结果：`.tmp-probe/upstream-v4-files.json`、`.tmp-probe/upstream-docs/`）。
2. **`package.json` / `pnpm-lock.yaml` 不可单文件摘取**——上游很可能升了依赖版本，须整体评估（本地是 pnpm workspace）。
3. **UI 类型检查需要大堆**：`NODE_OPTIONS=--max-old-space-size=12288 npx tsc -p packages/ui --noEmit`（8192MB 会 OOM）。
4. **不得整包 merge**：v4.0.0 是 sync 提交，会覆盖上表 97 个定制文件。
5. 每摘一项的流程：先补 spec/验收 → 实现 → 工程测试或运行验证 → 独立提交（`git add` 精确列文件，不 `git add .`）。
